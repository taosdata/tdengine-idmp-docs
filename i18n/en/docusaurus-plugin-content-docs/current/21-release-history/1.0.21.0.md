**Release Date: 2026-07-04**

## Highlight

1. KPI Attribute Management and Dashboard KPI Reports
Elements now support flexible definition and real-time tracking of KPI attributes. The dashboard has added a new KPI report type that allows direct addition of metrics from complex indicator lists, bringing key performance data into clear view and significantly improving monitoring and decision-making efficiency.

2. Real-Time Analytics Supports SPC Trigger Types
Real-time analytics now includes a Statistical Process Control (SPC) trigger type, which automatically initiates analysis when key process parameters show anomalous trends. Combined with multi-state windows and customizable judgment conditions, this helps quality teams quickly pinpoint root causes, shifting quality management from reactive responses to proactive prevention.

3. AI Assistant Integrates Skill Management and Collaboration Channels
The AI assistant has been deeply integrated with the skill management module, enabling users to search, receive recommendations, and apply best practices with a single click via natural language—eliminating the need for manual configuration. It also connects with Feishu, WeChat, and Telegram channels, allowing users to invoke the system’s AI capabilities (including information queries, notification alerts, and complex task execution) directly within their chat tools.
