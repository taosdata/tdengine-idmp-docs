**Release Date: 2026-07-04**

## Features

1. Admin backend adds a resource security configuration page for centralized management of access policies and security rules.
1. The sample download feature has been enhanced to display statistics including the number of assets, panels, analysis duration, and unit of measure (UOM) derived from samples, providing a comprehensive overview of sample usage.
1. Improved the sharing feature of the Analysis Workbench with shareable links and permission controls for more secure and efficient collaboration.
1. Analysis actions now integrate with Feishu, enabling real-time delivery of analysis results or alerts to Feishu groups for immediate team response.
1. The system now includes a built-in default enumeration set, ready to use out of the box with no manual setup required for faster attribute configuration.
1. Real-time analysis now supports multiple status windows, allowing simultaneous monitoring of various state changes for enhanced insight into complex processes.
1. Real-time analysis now supports SPC (Statistical Process Control) trigger types, enabling automatic analysis initiation when process anomalies are detected, supporting quality monitoring and alerting.
1. Symbols in the configuration dashboard now support binding attribute expressions, enabling dynamic data linkage and visualization.
1. Sample data can now be dynamically fetched from public servers, eliminating the need for manual import and enabling quick loading of the latest examples.
1. The panel now supports a KPI report type, putting key performance indicators at your fingertips for more efficient monitoring and decision-making.
1. Version control now supports E-signature mode for sign-off approval and change tracking, ensuring compliance and full traceability of operations.
1. Version control now covers panels, dashboards, and analysis modules, enabling unified management of configuration changes and history tracking.
1. Supports encrypted storage of sensitive information to ensure data security and compliance.
1. The Admin Backend now supports batch import of users and user groups via file upload or LDAP synchronization, enabling rapid organizational configuration.
1. Real-time analysis now supports the max-delay parameter, allowing you to set a maximum delay threshold for greater flexibility between timeliness and data completeness.
1. Elements now support KPI attribute management, allowing flexible definition and real-time tracking of key performance indicators for business insights.
1. The panel now supports directly adding metrics from the complex metric list, eliminating extra steps and streamlining configuration for greater efficiency.
1. Real-time analysis now supports unit derivation, automatically identifying and unifying data units without manual conversion to streamline analysis preparation.
1. Added a TSDB Explorer menu to the Admin Backend, providing quick access to the TSDB data exploration tool for more efficient querying and debugging.
1. Enhanced cross-element attribute references to enable direct participation in data calculation and display within panels and real-time analysis.
1. Imported tsgen configuration supports data replay, making it easy to reproduce historical data scenarios for configuration validation and performance evaluation.

## Improvements

1. Added a configuration item to enable or disable tag referencing for virtual tables, offering flexible control over data association behavior.
1. Improved rich text editing experience within dashboards, with live preview and quick formatting for more efficient content creation.
1. Optimized dashboard grouping with drag-and-drop sorting and batch adjustments for more efficient layout management.
1. AI chat add ops-wiki to database.
1. Improved full backup operations with a clearer workflow, progress indicators, and a one-click restore option for more reliable and user-friendly data protection.
1. The Analysis Workbench now supports directly adding new element attributes, enabling real-time data model extension without page switching for greater analytical flexibility.
1. The prediction algorithm in the Analysis Workbench now supports configurable parameters for flexible tuning to meet diverse business scenarios.
1. When exporting a panel as an image, you can now customize the file name for easier identification and management.
1. The status window in real-time analysis now supports string-type attributes, allowing more flexible condition evaluation and state classification.
1. The status window in real-time analysis now supports custom condition editing, allowing you to flexibly adjust analysis logic to fit various scenarios.

## Bug Fixes

1. The change operation requires a mandatory audit reason pop-up that cannot be skipped or dismissed.
1. When taosgen writes CSV files, the import process errors out and aborts if null values are present. Please ensure all data fields are complete.
1. The analysis workbench, after saving with downsampling enabled, cannot have downsampling canceled upon reopening, though it remains fully usable in subsequent panels and real-time analysis.
1. When editing a dashboard, the panel list does not include available panel templates.
1. Clicking the group menu in the dashboard main menu triggers an error, preventing normal group operations.
1. Remove forced AVG aggregation in AI panel generation to keep raw points.
1. AI question recommendations follow frontend system language.
1. In the state timeline panel, dragging the time slider causes the current data display to disappear, affecting data visibility after time range changes.
1. Downsampling in panels triggers an error when processing non-numeric metrics, affecting data aggregation and visualization. It is recommended to use numeric-type metrics for downsampling.
1. Occasional blank screen loading issues occur when opening a saved Analysis Workbench, affecting normal display and interaction.
1. Add download link to RCA report.
1. Shared links from the Analysis Workbench show permission errors or fail to load for other users.
1. After selecting an area on the scatter plot in the Analysis Workbench, the displayed content differs from the selection when reopening the view.
1. The envelope line saved in the Analysis Workbench fails to display correctly after reopening.
1. State transitions in the configuration may cause display anomalies in symbols, affecting real-time data visualization.
1. Ai chat generated analysis can not be saved.
1. Clicking an attribute item in the search results list triggers a system error, preventing you from viewing or editing the attribute details.
