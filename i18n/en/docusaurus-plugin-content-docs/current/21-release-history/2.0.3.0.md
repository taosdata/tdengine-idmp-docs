**Release Date: 2026-11-01**

## Highlights

1. Added process recipe management and the Batch Analysis Workbench — process recipes can be configured from multiple event templates, the event list can be filtered by recipe, and the matching batch events can be added to the Batch Analysis Workbench for quick comparison of process parameters across multiple stages.
1. Comprehensive AI upgrade — added expert mode and deep-thinking mode, the AI chat panel can quickly invoke expert assistants and preset skills, AI scheduled tasks can be configured and executed from the panel, and the security controls for AI agents have been substantially strengthened.
1. Enhanced SCADA panels and visualization — added attribute value setting, the format painter, default configuration items, Schema definitions, event support on graphics elements, and hover display of element paths and current values.

## Modules in This Release

AI and Agent Runtime, Data Ingestion and Attribute Management, Elements and Industrial Ontology, SCADA, Panels, and Dashboards, Real-Time Analytics and Events, Process Analytics and Models, System and Platform Administration

## Features

1. License Center heartbeat capability negotiation: clients advertising heartbeat.over_limit_code now receive code 6 with error details when quota is exceeded, while legacy clients keep the 0/3 behaviour; add N-1 compatibility e2e tests.
1. Added attribute-parameter support in external-source SQL for tag attributes — `${attributes['...']}` expressions are evaluated per element instance.
1. Downloadable Markdown/PDF reports for reportOutput skills and AI Function runs, including approved confirmation resumes.
1. Added a standalone virtual table repair tool that restores virtual table data from filesystem metadata when the IDMP database is accidentally deleted.
1. Added a format painter in the SCADA editor for quickly reusing element styles.
1. Added a default configuration module to the SCADA editor, providing a standard baseline for drawing process graphics.
1. Added process-recipe-based grouping in the event list, allowing filtering events by recipe, hierarchical grouping by event attributes, and Gantt-chart display of event duration.
1. Supports editing the system introduction of the root element.
1. AI chat supports scheduled tasks with natural-language creation and editing, execution history and notifications; results are published into the source conversation, with background authorization, pause/resume and failure recovery.
1. Added Metric and Tag reference types for data references on attributes of template-derived elements, with child attribute and quality-bit support.
1. Introduced event recipe management, allowing combinations of event attribute groups to be managed and applied to event analysis and display.
1. Third-party data sources now support SQL Server, expanding external data connectivity.
1. Added data-connection access control for users and user groups, restricting accessible TSDB instances and databases so data mapping and Explorer navigation follow the granted scope.
1. Added keyword search to the Agentic AI skills list: case-insensitive fuzzy matching on skill name, display name, and description, with server-side filtering; keyword is preserved across scope and sort changes.
1. Added filter and group capabilities to the attribute, panel, and analysis list pages, consistent with the event list.
1. Graphics elements in the SCADA editor show the bound attribute path and current value on mouse hover.
1. AI Chat adds expert mode so users can talk to domain experts with a bounded persona and skill set.
1. Added per-user personalization for visual panel/dashboard settings — users can adjust appearance without entering edit mode, saved locally in the browser.
1. Introduced a dedicated batch analysis panel with batch events at the core, supporting swimlane display of key parameters across process stages and multi-batch overlay/normalized comparison.
1. Events can be marked as invalid, and AI-based or manual analysis can automatically exclude them.
1. Analysis skills (Panel Insight, RCA, general-analysis, recommendations) now explicitly retrieve document knowledge-graph evidence (entities, relations, confidence), and degrade to previous behaviour when the graph is unavailable.
1. AI content safety filtering: three-layer sensitive-word blocking (question, tool arguments, retrieved documents) with localized safety prompts; sensitive document snippets excluded from retrieval; configurable word list seeded with 4-category blocklist and preserving operator custom entries across upgrades.
1. End-to-end trace propagation for the AI chat path, correlating the frontend, tda-server, ai-agent and backend callbacks with a single Trace ID.
1. AI chat supports a configurable deep-thinking mode: connection-level capability probing with persisted profiles, a deep-thinking toggle in chat, streaming reasoning display, and automatic fallback to the primary model.
1. AI MultiAgent collaboration protocol: the lead agent decomposes tasks and delegates to specialist sub-agents, passing full context (question, business data, resource IDs, execution constraints, output requirements) in the task message; per-agent tools, skills and delegation scope are configurable; results, errors, timeouts and cancellation are handled uniformly for a controllable, traceable workflow.
1. Optional pre-execution confirmation for AI tool calls. A per-user toggle (off by default, auto-saved) enables a confirmation card with execute, edit allowed parameters, skip, and cancel actions; covers AI Chat, AI Functions, panel insights and event RCA. Confirmation state is persisted and refresh-safe without re-execution; custom MCP tools are classified by risk annotations; IM channels are not covered yet.
1. Feishu channel AI chat now renders panel screenshots and clickable panel links instead of a resource-not-found error.
1. Add grant descriptions to the CLS license detail and quota pages; also fix free-license import self-healing and naming conflicts, and harden CLS P2P identity binding.
1. ELS sign-in now uses Feishu OAuth (QR/redirect) with database-backed accounts and a unified operation log; password login is removed, operation logs are restricted to an audit-viewer allowlist, and JWT sessions are capped at 8 hours.
1. Add the Diagnosis model type for whole-curve scoring and anomaly ranking across multiple elements sharing the same metric; models can be deployed on TDgpt and invoked from IDMP, with a dataset_type selector in dataset creation.
1. Publish OpenAI Codex plugin for IDMP.
1. Added name search to the event template list page, making it easy to locate templates among many.
1. Added Oracle as a supported third-party data source (Oracle 11g, 11.0.2.4 and later).
1. Column headers in IDMP list pages can now be reordered.
1. Event search results can now be sorted.
1. Added a management interface for asset data import tasks, supporting viewing, deleting, stopping, and pausing/resuming tasks.
1. Added image attachments to the AI Assistant input, including selection, thumbnail preview, removal, and vision-model understanding of the attached images.
1. Moved the admin console entry to the main menu, aligned the element explorer main menu with the main content by default, and updated the guided tour.
1. The top-level "Elements" node in the asset tree now supports renaming or aliasing.
1. Add DingTalk personal push notifications: a new "DingTalk (Personal)" contact point channel delivers alerts directly to each recipient's 1:1 chat.
1. Dashboards created from templates now support per-user personalization in view mode, consistent with regular panels/dashboards.
1. Stream-compute stop conditions now support the true-for duration check, preventing spurious data fluctuations from creating multiple windows.
1. The AI assistant can create complex 2D CANVAS/SCADA dashboards from natural-language requests or uploaded reference images, generating P&ID-style process topology, equipment and pipe layouts, instrument tags, and live attribute bindings, with automatic routing around equipment and labels.

## Improvements

1. Improved the analysis workbench — restored default box-zoom behavior on trend charts and kept the top action bar visible in fullscreen mode across panels, dashboards, and analyses.
1. Applied several UI refinements, including showing Path and Description on the panel list.
1. Rebuilt the set-attribute-value dialog for graphics elements in the SCADA editor and added event support on elements.
1. Applied multiple UX improvements — panel list shows Path/Description, unified icon placement in fullscreen views, and attribute filters/groups with quick actions on the attribute list.
1. Improved the notification rule editor and viewer — added enable/disable controls, default-value fallbacks, and action buttons for disabled rules.
1. Completed the JSON schema definitions and validation for chart configurations of panels and dashboards, with dedicated schemas for standard dashboards and KPI reports.
1. Upgraded realtime-analysis interpretation to evidence-validated insight delivery: structured decision reports gated by deterministic provenance validation (saved definitions, timestamp-verified raw data, rule replay, anomaly screening); honest limited-mode fallback with registered evidence when validation fails.
1. Optimized backend JSON reads to improve system processing performance.
1. Merged the download-as-image and download-as-PDF actions on panels/dashboards into a single export menu with image as the default option.
1. Improved event list filtering — fixed ineffective real-time analysis filters and switched to POST for large filter conditions to ensure stability.
1. Improved panel graphics elements in the SCADA editor — scalable fonts, multi-swimlane display, and panel selection now includes child-element panels.
1. Notification rules support message preview and test sending. Test sends verify the message pipeline without the rule minimum severity restriction and do not enter formal resend or non-repetition state.
1. The element list can now display attributes from all element templates as a union, enabling direct comparison of same-named attributes across templates, with missing values shown as "-".
1. Version control now supports undoing committed changes that have not yet been published.
1. Version control user branch names changed from User plus a UUID to the user name.
1. The 6-hour full reconcile no longer repeatedly sends ALTER COLUMN ref messages for ans_ virtual tables.
1. Improved the performance and observability of bulk element import via OPC, with live progress visibility and the ability to terminate tasks.
1. Enhanced the SCADA editor — Ctrl multi-select for batch adding elements to the analysis workbench, a bounded canvas with outer border, expression-based button links to the workbench, and in-app navigation without full page reloads.
1. Enhanced the analysis workbench — multi-select graphics elements (Ctrl) for batch adding, linked highlighting of the selected object across data list and panels, a legend color column in the attribute list, and marker-line tooltip colors consistent with the legend.
1. Harden License Center by binding remaining P2P handlers to CLS identity, retiring legacy ReportFreeLicense, protecting CLS management endpoints, and cleaning up SSO session/audit residuals.
1. Rework license signing so the trust root lives in ELS, introducing a v2 license payload that carries the CLS public key with chain verification; legacy CLS/SDK remain compatible, while new public free-license auth codes require an updated CLS.
1. Improved connector-line configuration in the SCADA editor — quick access to common settings (color, arrow size), saved custom colors for reuse, and arrow size no longer buried in the position settings.

## Bug Fixes

1. Added MFA login enforcement and configurable session (JWT) expiration to user security settings.
1. Claim LLM API keys dynamically from capability gateway instead of hardcoded built-in keys.
1. Fixed count-window streams being created without the required where time-range clause, which caused high TSDB memory usage — the where clause is now added automatically for such streams.
1. Fixed external SQL queries on tag attributes erroring when no rows are returned — the default value is now used, and an error is raised only when no default is configured.
1. Fixed the missing update date on enumeration-type metric attributes by querying real-time values in type-specific branches.
1. Fixed some float attribute values displaying as integers due to the type being taken from the first row in merged queries — decimal values now display correctly.
1. Fixed child attributes not displaying values even though their referenced data points have data.
1. Fixed changes to an attribute template's data reference type (e.g., to formula) not being synced to instantiated element attributes — template updates now propagate correctly.
1. Fixed stream-compute notifications from external TSDB instances not reaching Docker-deployed IDMP — the bundled Nginx now forwards the /eventReceive WebSocket endpoint.
1. Fix knowledge-graph extraction failures on large documents caused by the output token limit truncating the model reply; the extraction budget is derived from the remaining context with window bisection as a fallback.
1. Fixed parent attributes with child attributes showing no values when a child formula failed validation — attribute validation rules have been improved.
1. Fixed an error when deleting a panel whose underlying data no longer exists — deletion is now handled gracefully.
1. Fixed the mismatch between the Dashboard time range selector and the actual time range shown on a Panel's X axis — the Panel now displays its actual query range as a badge.
1. Fixed transaction errors when deleting element template attributes, caused by slow per-element reference checks — deletion now runs as an asynchronous batch with fallback error handling.
1. TDgpt raises Keras to 3.15.0 on Python 3.11 and later, and to 3.12.3 on older Python, so loading model weights no longer discloses local files through HDF5 external storage. CVE-2026-1669, GHSA-3m4q-jmj6-r34q.
1. Refactored the frontend IndexedDB data handling code, improving local cache read/write performance and code maintainability.
1. Fixed active external data source connections (e.g., SQL Server) missing from the connection list despite working direct fetch — list results now agree with direct fetch.
1. Fixed template-level analyses being unable to reference output columns of another template-level analysis — the virtual supertable now carries analysis output columns, so previously rejected analyses can be created.
1. Fixed errors occurring when recalculating analysis history data.
1. Clarified the scheduled-report notification channel dropdown, which silently filtered out newly added channels — a tooltip now explains the filter rule.
1. Fixed a null-pointer error when creating streams for event analyses without input attributes (a null getConnId() produced a literal "null" database name) — stream creation now works.
1. Fixed German-style (non-ISO) date entries being rejected while English-style dates were accepted — absolute times are now parsed via the system display template with normalized range text.
1. Fixed unfiltered virtual-supertable full queries being retried repeatedly on timeout and inflating memory — heavy SQL verification now executes exactly once.
1. Fixed SMTP test emails failing in mail routing when the template name is null — test emails now send successfully.
1. Fixed data backup showing no progress for extended periods.
1. Fixed element notification rules skipping automatic delivery on H2-based deployments (Docker Compose default) caused by a MySQL-specific operator unsupported by H2 — automatic notifications are delivered again.
1. Restore reference reading and script execution for user-uploaded skills in both the root agent and sub-agents.
1. Fixed missing or empty trend lines in the batch analysis workbench when multiple batches were added concurrently — each batch now keeps its own attribute configuration and renders its curves correctly.
1. Fixed audit log timestamps displaying incorrectly — times are now stored as timestamps and rendered in the browser's local timezone.
1. Fixed contact points being visible only to their creators — the notification channel list and rule editor now show all contact points, while per-user default contact points remain isolated.
1. Fixed the event template list pagination total exceeding the visible row count by one (demo template indexed by mistake), eliminating blank rows on the last page.
1. Fixed high CPU usage caused by table-creation events retrying endlessly when the underlying database or analysis table no longer exists — such errors now trigger a circuit breaker.
1. The AI service now starts on deployments whose data directory path contains an administrator-created symbolic link.
1. Fixed MD file import failures with "413 Request Entity Too Large" when uploading files around 60M — the Nginx body size limit is now raised to 1G.
1. A single custom skill with a malformed SKILL.md header no longer makes every custom skill unreadable.
1. Fixed external data source connections (e.g., SQL Server) disappearing from the connection list when TDengine-specific permissions were configured — connections of all types now display correctly.
1. Fixed attributes with granted permissions showing a "no permission" error when their value was null — permission interception is relaxed for non-TDengine connections.
1. Fixed SCADA JSON import failing with an "element ID not found" error.
1. Fixed element deletion failing with a "workspace is locked" error caused by the root-node marker — element deletion now works normally.
1. Fixed child element instances not following an element template's data-reference change to SQL Server and being impossible to edit — elements now support custom connection settings.
1. Fixed elements imported via MD modeling not following the declaration order in the file — element IDs are now assigned in declaration order.
1. Resolved MCP schema incompatibility that made OpenCode and other compatible agents fail tool schema validation and interrupt conversations after HiAgent compatibility was added; standard JSON Schema is now the default and legacy clients can keep compatibility via the openapi3 option.
1. Fixed histograms failing to render due to panel personalization settings.
1. Fixed the lack of name search on the analysis list page — users can now search analyses by name instead of paging through hundreds of entries.
1. Fixed tag/column DDL failures for KPI display names containing hyphens — hyphens are now properly escaped/quoted before being used in DDL.
1. Fixed the `meta2d.active` TypeError triggered when dragging graphics elements on the 2D SCADA canvas — dragging now works normally.
1. Fixed the limit-configuration connection dropdown only listing TDengine — third-party data source connections are now selectable for external references.
1. Fixed the missing-file error when enabling Version Control on hosts without native git — a pre-check (git --version, 10s timeout) now fails fast with a clear error.
1. Fixed saving an event template silently clearing attribute definitions and leaving analysis associations dangling — valid saves now preserve definitions, IDs, and analysis links, while invalid associations fail validation.
1. Aligned the element Group list page with the child-element and element-search list pages, including consistent columns and the right-side attribute configuration.
1. Fixed element tree deletion being extremely slow (a 200-element tree only progressed ~20% in an hour) — the deletion pipeline is now batch-optimized.
1. Fixed the misalignment between the event line and the trend chart Y-axis start line in the analysis workbench.
1. Fixed the spurious "Health check timed out" error and red point status shown after modifying an element attribute — point status now displays correctly.
