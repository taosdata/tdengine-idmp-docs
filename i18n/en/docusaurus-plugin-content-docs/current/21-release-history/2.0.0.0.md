## Features

1. Set built-in AI token TTL to 7 days and update DeepSeek default model to deepseek-v4-flash.
1. The sample data loop write feature now supports configuring historical event windows, allowing flexible definition of event time ranges for diverse testing and simulation scenarios.
1. The Analysis Workbench now features annotation support, allowing users to add notes on charts and data points for enhanced team collaboration and information sharing, improving the readability and traceability of analysis results.
1. Support multi-language prompt display for built-in skills.
1. Upgrade MCP server management to template mode.
1. Sync sidebar tree and breadcrumb on channel detail URL navigation.
1. AI Function page supports direct SKILL file upload.
1. The general element page now supports viewing version history for easy change tracking.
1. Add Agentic AI connection management with /agent API.
1. Actions now support the AI Agent type, enabling AI‑based autonomous decision‑making and automated execution.
1. Analysis workbench supports saving AI insights as panel notes, optimize PDF report export.

## Improvements

1. Provide official recommended model parameter configurations.
1. The Analysis Workbench now supports batch addition of events, allowing you to import multiple events at once for improved efficiency and ease of use.
1. Automatically validates the TSDB version required for KPI attributes, tag references, and status windows.
1. Optimize upload and support more file types (38 types tested).
1. Optimize upload error handling and support more file types.

## Bug Fixes

1. Add download links for data interpretation and root cause analysis with markdown and PDF support.
1. Add missing frontend i18n configuration in IDMP.
1. In dark mode, the AI Function conversation window occasionally displays in light mode, affecting interface theme consistency.
1. Email server configuration now supports no‑authentication mode, allowing mail delivery without providing a username or password.
1. Force UTF-8 stdio in Python runtime and improve crash observability on Windows.
1. Stub element/template index endpoints as no-ops to fix delete endpoint errors.
1. Hover effects are not triggered for canvas symbols in edit mode, resulting in missing interactive feedback.
1. The event search function is abnormal, displaying chaotic results that fail to accurately match the target events.
1. The window analysis added in the Analysis Workbench cannot be deleted, affecting management flexibility.
1. The change reason field appears incorrectly in the model management page and should not be displayed, affecting interface cleanliness and operational smoothness.
1. State transitions in the configuration may cause display anomalies in symbols, affecting real-time data visualization.
1. Once historical events generated by a real-time analysis are manually deleted, the same analysis instance cannot regenerate them.
1. AI chat now searches user-uploaded documents for non-TDengine topics.
1. After opening a configuration dashboard from the configuration list in the dashboard main menu, clicking edit triggers an error indicating that the corresponding element cannot be found.
1. Multiple attribute fields cannot be edited individually; all modifications must be made via the attribute template.
1. KPI attribute save operation failed.
1. The Y-axis settings in the Analysis Workbench fail to apply, affecting chart data display.
1. When viewing the child element panel of an intermediate element in the element browser, a system error is triggered and the panel fails to load.
1. Clicking any filter item in the element filter and then clicking the top‑left logo triggers a system error, causing abnormal page behavior.
1. The offline documentation page experiences abnormal style rendering when opened, affecting the normal viewing of document content.
1. After canceling the limit conditions of an attribute template, attempting to set them again triggers a system error.
1. After deleting a dashboard from the left tree structure in the dashboard main menu, the right-side list page does not refresh automatically and requires a manual refresh to update the display.
