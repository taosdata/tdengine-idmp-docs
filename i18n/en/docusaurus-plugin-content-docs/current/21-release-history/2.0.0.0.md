## Features

1. Set built-in AI token TTL to 7 days and update DeepSeek default model to deepseek-v4-flash.
1. The sample data loop write feature now supports configuring historical event windows, allowing flexible definition of event time ranges for diverse testing and simulation scenarios.
1. The Analysis Workbench now features annotation support, allowing users to add notes on charts and data points for enhanced team collaboration and information sharing, improving the readability and traceability of analysis results.
1. Support multi-language prompt display for built-in skills.
1. Upgrade MCP server management to template mode.
1. Sync sidebar tree and breadcrumb on channel detail URL navigation.
1. AI Function page supports direct SKILL file upload.
1. The general element page now supports viewing version history for easy change tracking.
1. Add Agentic AI connection management with /agent API.
1. Actions now support the AI Agent type, enabling AI‑based autonomous decision‑making and automated execution.
1. Analysis workbench supports saving AI insights as panel notes, optimize PDF report export.
1. Add AI Function creation entry from any page with auto-filled context type.
1. Add send_im_message agent tool for delivering Markdown reports to user's bound Feishu/Telegram/WeChat accounts.
1. Add slash skill commands to AI chat with autocomplete and filtering.
1. Panel templates now support custom naming patterns for quick identification and categorized management.
1. Enable file-level editing for user-defined skills.
1. Support global document uploads and tree-based element picker.
1. Add histogram, candlestick, and heatmap panel types.
1. Version control now supports selecting a target version from the version list for rollback, enabling quick restoration to a specific state.
1. Add CLS identity signature and ELS verification with Java SDK support.
1. Split RCA and general analysis, per-module standalone analysis.
1. RCA supports cross-element attribute correlation analysis.
1. Add DingTalk IM channel support with proactive send.
1. The element attribute list page now supports filtering by name, helping you quickly locate target attributes.
1. Click a point on the configuration canvas to quickly view its trend chart for instant data analysis.
1. When accessing the Analysis Workbench via a shared link, the panel interpretation feature fails to load properly, preventing the interpretation content from being viewed.
1. After deploying All-in-One via the Linux installation package, the real-time analysis module fails to start properly, making the feature unavailable.
1. The anomaly detection feature in the panel's window analysis cannot select a target, preventing configuration from being completed.

## Improvements

1. Provide official recommended model parameter configurations.
1. The Analysis Workbench now supports batch addition of events, allowing you to import multiple events at once for improved efficiency and ease of use.
1. Automatically validates the TSDB version required for KPI attributes, tag references, and status windows.
1. Optimize the UI styles of the MCP list, function list, and MCP editing page.
1. Unit names are now required to be unique only within their category, rather than globally, offering greater naming flexibility.
1. Enrich general analysis content, merge general and root cause analysis into one button.
1. The Analysis Workbench now supports copy and paste, enabling fast reuse of configurations and data for improved operational efficiency.
1. Introduce ruff linter for tdmodel and integrate into CI.
1. Multi-lane trend charts now support independent Y-axis settings for each lane, meeting the needs of comparative analysis across different data scales.
1. The bar chart panel now supports custom Y‑axis ranges, allowing you to focus on specific data intervals for more flexible analysis.
1. Show localized provider connection error messages in AI UI.
1. Stabilize AI recommendation and recommendation generation E2E tests.
1. Add knowledge retrieval E2E test with references assertion.
1. AI and model-related pages now adopt a unified visual style, ensuring interface consistency and smooth interaction.
1. Add WeChat enable toggle to channel detail page, fix channel state isolation on type switch.
1. Harden LLM logs with centralized redaction and structured logging.
1. Element information now includes creation time for easy record tracking and change history reference.
1. Downsampling has been removed from the table panel.
1. Optimized the layout of the panel edit page by moving the downsampling button to the top area for more intuitive and convenient operation.
1. AI buttons auto-disabled when connection is unavailable, with tooltip showing reason.
1. Optimized the attribute operation workflow in the Analysis Workbench for improved configuration efficiency and interaction responsiveness.
1. Import and export operations have been upgraded to asynchronous task mode. Task progress and results will be pushed to the frontend in real time via notifications, eliminating the need to wait for page responses and improving the user experience.
1. Optimized child element list expansion performance for faster loading and responsiveness under large data volumes.
1. Refactored the boundary value configuration for panels including trend charts, bar charts, and the Analysis Workbench to enhance flexibility and accuracy in data visualization.
1. The attribute details page now supports viewing and clicking to navigate to the associated attribute template.
1. During resource management operations (delete, update, and add), an unexpected system crash may result in failure to recover automatically, posing a stability risk.
1. Provide multi-platform index recovery scripts to streamline the index recovery process after anomalies and improve troubleshooting efficiency.
1. Thresholds in panel configuration should not be set independently; they should be managed as part of the color scheme to maintain visual consistency.
1. Optimized the paging display of the left tree structure to keep it aligned with sibling elements after page turns, improving browsing consistency.
1. Added a "Share" entry to the more options menu (···) of panels and dashboards for quick link sharing.
1. Sample backend enhancement: configuration data is now cached, significantly improving read performance and system responsiveness.
1. Optimized canvas dragging in configuration editing for smoother interaction and faster response.
1. Optimize upload and support more file types (38 types tested).
1. Optimize upload error handling and support more file types.
1. Use LiteParse as default PDF/Office/image-to-Markdown backend for improved document Q&A quality.
1. AI recommended panels not relevant to customer data, optimize element recommendation logic.
1. Optimized Git repository initialization to automatically ignore temporary files from file transactions, preventing accidental commits and keeping the repository clean.
1. AI intent routing and response language stability.
