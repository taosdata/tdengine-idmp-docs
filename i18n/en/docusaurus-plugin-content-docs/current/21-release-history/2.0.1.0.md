**Release Date: 2026-09-02**

## Highlights

1. New knowledge graph for document management: User-uploaded documents are automatically processed to extract entities and relationships, generating bilingual (zh/en) knowledge graphs. AI Chat can query the graph for context, so answers are grounded not only in keyword matches but also in structured knowledge associations; product manuals and other foundation documents are available out of the box as graph content.
2. Data prediction trigger for real-time analysis: Real-time analysis adds a data prediction trigger type that automatically runs predictive analysis when trigger conditions are met, helping identify trends and anomalies in advance and giving real-time monitoring a forward-looking capability.
3. Unified email gateway and smoother upgrades: A unified email gateway centralizes sending of registration and invitation emails for more reliable and manageable notifications; an internal asynchronous migration mechanism smoothly migrates element data for a smoother upgrade experience.

## Features

1. Provide a unified email gateway for centralized handling of user registration and invitation emails, ensuring reliable delivery and easy management.
1. Add knowledge graph feature with document entity extraction, dual-language graphs (zh/en), graph visualization page, and read-only query pipeline for AI QA context.
1. Real-time analysis now includes a data prediction trigger that automatically executes predictive analysis when conditions are met, helping identify trends and anomalies in advance.
1. IDMP MCP plugin published on Workbuddy platform with connector packaging support.
1. AI communication adds Whatsapp channel support.
1. The table panel now supports row-column swapping and adds multiple configuration options for more flexible data display.
1. Attribute lists can now be saved as Asset panel tables for quickly building asset views and centralized data management.
1. Add two-entity path query to the knowledge graph page; improve filter, relation list and legend UX.

## Improvements

1. Optimized the entry points for import, export, and download lists with a unified layout for more efficient batch operations and clearer interface.
1. Provides an internal asynchronous migration mechanism to smoothly migrate element data to version 2.0.1.0.
1. The data imputation algorithm in the Analysis Workbench supports real-time invocation, allowing you to fill missing data instantly without waiting and improving analysis efficiency.
1. Update composite metric examples with 6 new industry scenarios in zh/en/es/ko.
1. Paginate skills and functions libraries with server-side sorting.
1. Improved the performance of CSV loading for sample data, significantly reducing import time and enhancing the loading experience under large data volumes.
1. Optimized element deletion performance for significantly faster response times in large-scale data scenarios.
1. Optimized the loading performance of the child element list in the element browser for faster response and smoother scrolling under large datasets.
1. Added element sorting option in basic system configuration, allowing custom display order of element lists to improve browsing and lookup efficiency.
1. Stabilize KG e2e tests with dedicated fixture, skip static corpus scan, fix gitignore false-exclusion.
1. Require confirm=true for MCP manage_analysis DELETE operation.
1. Added a "+" button to the dashboard preview page for quick creation of a new dashboard.
1. Sample data configuration files now support relative time expressions (e.g., now - 7d) for event timestamps, enabling flexible definition of event occurrence times.
1. Optimized the state timeline display for clearer state changes and easier-to-read time intervals.
1. IDMP instances in the cloud service continue to send emails via internal SMTP.
1. Update API Key table and button styles.
1. Commercial edition license content updated.
1. Improve knowledge graph entity accuracy and UI experience.
1. Stamp known-empty files as processed in the manifest so updates do not re-extract them.
1. Add entity cleaning pipeline for knowledge-graph init and update, dropping version/date/numeric junk entities.
1. Filtered results and grouped list pages display content consistent with the original list page for a unified browsing experience.
1. Configurable request body size limit for MCP Streamable HTTP endpoint (default 4MB).
1. Support doc/docx/ppt/pptx uploads and remove markitdown (reduce ~150MB).
1. Annotations in the Analysis Workbench can now be downloaded with samples for quick reuse and import.
1. Added a download progress indicator to the sample data download page, providing real-time status feedback and improving the waiting experience.
1. The TDasset section has been removed from the sample data configuration JSON file, simplifying the configuration structure.
1. The list page now clearly indicates the active sorting column, helping users quickly identify the current sorting state.
