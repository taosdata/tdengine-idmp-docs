**Release Date: 2026-09-30**

## Highlights

1. Industrial Ontology Upgrade: Added an element relationship visualization page that shows how devices relate to one another as a graph, for intuitive viewing and flexible editing.
1. Enhanced Data Modeling: Added Markdown-based asset modeling with multi-file upload and concurrent processing; elements can now be created without a template, greatly improving data modeling efficiency.
1. External Data References: Added federated queries that can reference time-series and relational data from external databases; custom tags are now supported on elements and events, and tags can be used to build multi-level structures for filtering and displaying information.

## Features

1. Attributes now support adding general sub-attributes, enhancing attribute hierarchy management and data organization.
1. Panel boundary value configuration adds a “Display on Series” option, allowing thresholds to be shown directly on the corresponding series for intuitive comparison.
1. Element basic info statistics are now integrated into attributes for unified viewing and management.
1. Now supports data reference attributes for external data connections including MySQL, PostgreSQL, and InfluxDB.
1. Internal relational data now supports persistence to PostgreSQL, enhancing storage flexibility and scalability.
1. Added filtering to child element and attribute list pages for quick conditional filtering and improved lookup efficiency.
1. Measurement points in the configuration dashboard now support one-click access to the Analysis Workbench for deeper analysis.
1. The attribute list in the Analysis Workbench now displays more attribute information and supports pop-up detail viewing, improving information access efficiency and operational convenience.
1. The panel's underlying chart library, ECharts, has been upgraded to 6.1, enhancing chart rendering performance and compatibility.
1. AI Function independent analysis — element attributes.
1. AI Function independent analysis — dashboard.
1. AI Function independent analysis — realtime analysis detail.
1. Added a new file-based import mode for data models, enabling quick data model import via files.
1. The Element Browser now supports element relationship graph display with direct editing, enabling intuitive management of element relationships.
1. The event list now supports filtering and grouping by event attributes for efficient event screening and categorization.
1. The output timestamp in real-time analysis can now be set to the original data timestamp, preserving the native time information of the data.
1. The anomaly detection in real-time analysis now supports multivariate analysis, enabling simultaneous correlation of multiple metrics for precise identification of anomalies in complex scenarios.
1. Event import has been enhanced to support importing event attributes and their values, improving the completeness and flexibility of event data import.
1. Add WeCom (enterprise WeChat) bot end-to-end support to IDMP Channel.
1. Centralized AI Agent runtime settings with IDMP-side query/update API and Admin Console config page.
1. Expressions in standard panels and real-time analysis now support direct reference to KPI attribute sub-attributes, simplifying configuration and improving flexibility.
1. Official user documentation now offers a PDF version for offline reading and download.
1. Panels and dashboards now support exporting as PDF files for offline viewing and sharing.
1. Dashboards now support parameter filtering, enabling dynamic data filtering by specified parameters for greater analytical flexibility across scenarios.
1. OPC UA and CSV imports now support automatic generation of virtual ordinary tables, streamlining data model mapping and improving import efficiency.
1. The output attributes of real-time analysis now support referencing attributes from other elements, enabling cross-element data correlation and computation.
1. Optimized the EAI time picker and multiple operations, further improving system usability and operational smoothness.
