# 5.8.7 Embedding Components

A canvas screen is not just a "diagram" — it can also embed various display components so the screen directly presents live video, external web pages, live data tables, and scale rulers. The following introduces the component types that can be embedded in a canvas; for embedding existing analysis panels, see [5.2.3 Panel Symbols](../02-symbol-library.md).

## 5.8.7.1 Video

The video symbol connects to a live video stream, presenting the on-site view directly within the screen.

## 5.8.7.2 Web Page (iframe)

The web page symbol embeds external web page content, presenting external system pages within the canvas.

## 5.8.7.3 Table

The table symbol refreshes multiple attributes in real time, arranging the key attributes of several elements into a live table. It is commonly used for alarm lists, equipment status overviews, and per-shift readings.

## 5.8.7.4 Ruler

The ruler symbol places a scale ruler on the screen. By configuring properties such as tick interval, orientation, tick position, showing tick labels, and showing the current value, it presents the scale indication of a value at a glance.
