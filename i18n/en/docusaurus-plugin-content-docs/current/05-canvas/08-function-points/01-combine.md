# 5.8.1 Setting Combined Symbols

Select multiple symbols on the canvas, right-click, and choose **Group** to combine them into one combined symbol. Combined symbols organize the screen in any way you want and make symbols reusable.

## 5.8.1.1 Procedure

1. Select multiple symbols on the canvas by box selection or by clicking them one by one while holding `Ctrl`.
2. Right-click and choose **Group** from the context menu; the selected symbols are combined into one combined symbol.
3. The combined symbol can be dragged and scaled as a whole. Double-click to enter the group and continue processing any sub-symbol; press `Esc` to exit sub-symbol editing.

:::warning
Before ungrouping, confirm that the data on the combined symbol is no longer needed: choosing **Ungroup** from the context menu (shortcut `Ctrl/Cmd + Shift + G`) prompts that ungrouping will lose the data of the combined symbol.
:::
