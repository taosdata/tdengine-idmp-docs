# 5.8.5 Setting Attribute Animations

IDMP has many built-in symbol animation effects and also allows frame-by-frame custom animations, making the monitoring screen vivid and intuitive.

## 5.8.5.1 Adding an Animation

Add an animation to a symbol and set the animation duration, animation effect, number of loops, next animation tag, whether to play automatically, and whether to maintain the animation state.

## 5.8.5.2 Built-in Animations

Built-in animations include: none, bounce up and down, bounce left and right, heartbeat, success, warning, error, show off, rotate, and custom.

## 5.8.5.3 Custom Animations

Create frame-by-frame custom animations by adding animation frames.

## 5.8.5.4 Triggering

In addition to autoplay, animations can be triggered by events: event actions support execute animation, pause animation, and stop animation. For example, configure "execute animation" on a "symbol attribute value change" event to play an animation when the data changes. See [5.8.6 Setting Symbol Events](./06-events.md).
