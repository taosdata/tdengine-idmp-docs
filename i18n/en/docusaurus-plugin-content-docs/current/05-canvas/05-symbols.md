# 5.5 Symbol

Symbols are the basic units that make up the monitoring screen, just like Lego blocks. Each device icon and closed shape is a symbol. By combining different symbols, you can build a complete industrial monitoring system.

Symbols have various properties, such as color, background color, size, displayed text, progress, value, and state. This page covers appearance settings and mouse tips; events and other data-driven configurations — combining symbols into a combined symbol, setting symbol states, values, progress, and animations — are covered in [5.8 Function Points](./08-function-points/index.md).

## 5.5.1 Appearance Settings

After selecting a symbol, configure its visual attributes in the **Appearance** tab of the right-hand properties panel. The main collapsible groups are:

### 5.5.1.1 Style

Stroke and fill: color, line type, line width, line gradient, background (solid/linear/radial gradient), opacity, shadow, hover/selected colors, etc.

### 5.5.1.2 Position and Size

X, Y, width, height, rotation angle, corner radius, etc.

### 5.5.1.3 Text

Set the font, size, color, style, weight, line height, alignment, position, etc. of the text displayed on the symbol.

### 5.5.1.4 Image

You can upload images as the appearance or background image of the symbol.

Line symbols also provide an **Endpoint** group (start/end coordinates and line caps); see [5.7 Line](./07-lines.md).

## 5.5.2 Mouse Tips

Display mouse tip information when the mouse hovers over a symbol. Two methods are supported:

1. Write mouse tips using Markdown syntax
2. Write Mark functions to display the return value of the function
