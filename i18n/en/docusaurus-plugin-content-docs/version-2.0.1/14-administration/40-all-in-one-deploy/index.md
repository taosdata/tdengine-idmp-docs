# 14.13 TDengine All-in-One Installation Overview

TDengine All-in-One combines TSDB, IDMP, and TDgpt into a unified deployment package.

- **TDengine TSDB:** Time-series data storage.
- **TDengine IDMP:** Industrial data modeling, contextualization, visualization, and application development.
- **TDgpt:** Machine learning and analytics capabilities.
- **TDmodel:** Model management and execution.

## 14.13.2 Overview

Apex is the unified entry point for TDengine All-in-One installation and deployment. It supports Linux host deployments, Windows host deployments, and Docker deployments.

:::note
TDmodel is not supported in Linux or Windows host-mode deployments.
:::

## 14.13.3 General Requirements

Use `root` on Linux or an administrator account on Windows. Docker deployments require Docker to be installed and running. Refer to the selected platform guide for complete environment requirements and deployment commands.
