# 4.4 仪表板

TDengine IDMP 中的仪表板是自由布局的画布，可将多个面板组合到单一视图中。单个面板展示某个元素的一张图表，而仪表板则汇集来自整个元素层级的面板——多张图表、仪表盘图、表格和统计值面板排列在网格中——让操作员和工程师对某项资产或工艺一目了然。

## 4.4.1 仪表板标签页

在资产树中导航到任意元素，点击**仪表板**标签页即可访问其仪表板。

仪表板列表上方的工具栏左侧提供以下控件：

- **分类：** 按分类标签筛选仪表板，默认为"全部"。
- **视图切换：** 两个图标按钮，用于在仅显示已保存的仪表板与同时显示来自父元素或子元素的仪表板之间切换。

右侧提供以下控件：

- **+（新建仪表板）：** 打开仪表板编辑器创建新仪表板。
- **复制：** 复制已有仪表板。
- **刷新：** 重新加载仪表板列表。
- **设置：** 配置仪表板列表偏好。

列表以以下列显示该元素所有已保存的仪表板：

| 列 | 说明 |
|---|---|
| **名称** | 仪表板名称 |
| **路径** | 该仪表板所属的元素路径 |
| **描述** | 可选描述 |
| **模板** | 该仪表板是否从模板创建 |
| **分类** | 分配给该仪表板的分类标签 |

将鼠标悬停在某行上，可显示查看、编辑或删除该仪表板的操作按钮。

若某个仪表板由**仪表板模板**创建，且其中包含基于子元素模板的面板模板，则打开该仪表板后，需要在**级联元素选择器**中选择当前元素下的对应子元素。该选择应限定为当前元素层级内的子元素，以确保模板面板绑定到正确的数据来源。

## 4.4.2 创建仪表板

创建新仪表板的步骤：

1. 点击仪表板标签页工具栏中的 **+** 按钮。
2. 仪表板编辑器打开，显示空白网格画布。
3. 从左侧面板库拖拽或新建面板，将面板添加到画布。
4. 在右侧面板中配置仪表板名称和设置。
5. 点击**保存**保存仪表板。

仪表板也可以从面板的查看模式创建：在面板工具栏中使用**保存到仪表板**，将该面板添加到新建或现有的仪表板中。

## 4.4.3 仪表板编辑器

仪表板编辑器分为三个区域：左侧面板库、中间画布和右侧设置面板。

### 4.4.3.1 编辑器工具栏

| 控件 | 说明 |
|---|---|
| **返回** | 返回仪表板标签页 |
| **保存** | 保存仪表板的所有更改 |
| **放弃** | 放弃更改 |
| **+（新建面板并插入）** | 打开面板编辑器创建新面板并添加到此仪表板 |
| **时间选择器** | 设置仪表板所有面板的时间范围 |
| **缩小** | 将时间范围扩展到下一级别 |
| **刷新** | 重新加载所有面板数据 |
| **自动刷新** | 设置自动刷新间隔（关闭、5 秒、10 秒、30 秒、1 分钟等） |
| **全屏** | 将仪表板扩展为填满浏览器窗口 |

### 4.4.3.2 左侧面板：面板库

左侧面板显示当前元素可用的面板，以树形结构组织：

- **面板：** 列出属于当前元素的所有已保存面板，展开可查看面板名称。
- **子元素：** 列出子元素，其面板也可包含在此仪表板中。

将面板从库中拖拽到网格上即可添加到画布。

### 4.4.3.3 中间：网格画布

画布为 12 列网格。面板可通过从库中拖拽或点击工具栏的 **+** 按钮来放置。放置到画布后，面板可以：

- 通过拖拽右下角的调整大小手柄来**调整大小**。
- 通过拖拽面板标题到网格新位置来**移动**。
- 通过点击面板的关闭图标来**删除**。

面板根据仪表板当前的时间范围设置在画布上渲染实时数据。

### 4.4.3.4 右侧面板：仪表板设置

| 字段 | 说明 |
|---|---|
| **名称** | 仪表板标题（必填） |
| **描述** | 仪表板的可选描述 |
| **分类** | 用于筛选和组织仪表板的一个或多个标签 |
| **通知规则** | 在仪表板级别配置告警规则 |
| **过滤条件** | 声明基于元素模板属性的自定义过滤条件，供查看者筛选面板数据，详见 [4.4.6 自定义过滤条件](#446-自定义过滤条件) |

## 4.4.4 向仪表板添加面板

有三种方式向仪表板添加内容：

**从面板库拖拽。** 左侧面板显示当前元素所有已保存的面板。将任意面板拖拽到画布上，面板将以其保存的数据配置和可视化设置进行渲染。

**新建面板。** 点击工具栏中的 **+（新建面板并插入）** 按钮，在新标签页中打开标准面板编辑器。保存新面板后，它将被添加到仪表板画布中。

**从面板查看模式添加。** 在全视图查看任意面板时，打开面板卡片的 **⋮** 菜单并选择仪表板操作，或导航到仪表板标签页，从面板库拖拽到画布。

## 4.4.5 仪表板查看模式

在仪表板列表中点击 **查看**，可在全视图模式下打开仪表板。

### 查看模式工具栏

| 控件 | 说明 |
|---|---|
| **返回列表** | 返回仪表板标签页 |
| **编辑** | 打开仪表板编辑器 |
| **收藏** | 将此仪表板标记为收藏以便快速访问 |
| **时间选择器** | 设置仪表板所有面板的时间范围 |
| **缩小** | 将时间范围扩展到下一级别 |
| **刷新** | 重新加载所有面板数据 |
| **自动刷新** | 设置自动刷新间隔 |
| **分享** | 生成指向此仪表板视图的限时分享链接 |
| **数据缩放** | 开启数据缩放模式，在图表上框选来缩放时间范围 |
| **全屏** | 将仪表板扩展为填满浏览器窗口 |
| **注解** | 打开注解面板，为此仪表板添加文本注解 |
| **过滤条件** | 打开过滤条件对话框，按声明的过滤字段筛选面板数据（仅当仪表板声明了过滤条件时显示，详见 [4.4.6 自定义过滤条件](#446-自定义过滤条件)） |

### 注解

注解让用户为仪表板附加文字备注。操作方式与面板注解相同，详见 [4.1.5 注解](./01-panels.md#415-注解)。

## 4.4.6 自定义过滤条件

仪表板支持声明自定义过滤条件：编辑者基于元素模板的属性发布一组可过滤字段，查看者在查看仪表板时为各字段组合操作符和值，即可按业务维度（如电压等级、设备型号）筛选整个仪表板的数据，无需修改面板本身。

### 4.4.6.1 声明过滤条件

过滤条件在仪表板编辑器右侧设置面板的**过滤条件**分区中声明，并随仪表板一并保存。

1. 打开仪表板编辑器，在右侧设置面板中展开**过滤条件**分区，点击**添加**。
2. 在弹出的模板属性选择器中选定某个元素模板下的一个属性。
3. 系统自动将别名填充为属性名、将输入提示（placeholder）填充为「值（属性值类型）」，两者均可修改。
4. 重复上述步骤可添加多条过滤条件；点击删除图标可移除某条。同一仪表板内别名必须唯一。
5. 保存仪表板后，过滤条件即对查看者开放。

### 4.4.6.2 应用过滤条件

仪表板声明了过滤条件时，查看页面左上角显示一个过滤图标按钮（未声明则不显示）。

1. 点击过滤图标按钮，弹出过滤条件对话框。每个过滤字段占一行：别名标签、操作符下拉框和值输入框，值输入框的提示文字取自声明时设置的输入提示。
2. 为需要筛选的字段选择操作符并填入值：
   - 操作符候选集按属性的值类型自动裁剪，与面板属性过滤条件一致，见下表。
   - `BETWEEN`/`NOT BETWEEN` 显示两个值输入框，分别填写下界和上界。
   - `IS NULL`/`IS NOT NULL` 无需填写值。
3. 点击**确定**：对话框关闭，所有面板自动重新查询，过滤图标按钮右上角的角标显示当前生效的条件个数。
4. 点击对话框中的**重置**可清空所有条件（操作符恢复为 `=`、值清空），点击**确定**后生效；清空某条件的值后，该条件不再参与过滤。

| 属性值类型 | 可用操作符 |
|---|---|
| 数值 | `=`、`!=`、`>`、`>=`、`<`、`<=`、`IN`、`NOT IN`、`BETWEEN`、`NOT BETWEEN`、`IS NULL`、`IS NOT NULL` |
| 时间戳 | 同数值类型 |
| 字符串 | `=`、`!=`、`>`、`>=`、`<`、`<=`、`IN`、`NOT IN`、`LIKE`、`NOT LIKE`、`IS NULL`、`IS NOT NULL` |
| 布尔 | `=`、`!=`、`IN`、`NOT IN`、`IS NULL`、`IS NOT NULL` |

`IN`/`NOT IN` 的多个值之间使用英文逗号分隔。

:::tip
`LIKE`/`NOT LIKE` 的匹配模式由用户自行提供：`%` 和 `_` 作为通配符生效。例如，值输入 `%301` 表示后缀匹配，输入 `%一号%` 表示包含匹配，输入普通文本则表示精确匹配。
:::

### 4.4.6.3 生效范围

过滤条件按元素模板定向生效，混合模板的仪表板不会出现误过滤。

- 仅当面板查询的元素所属的元素模板与过滤条件声明的元素模板一致时，该面板的数据才会被过滤，其他面板不受影响。
- 面板无需引用过滤属性即可被过滤；若被查询元素上不存在过滤条件声明的属性，则该元素不受影响。
- 对于聚合全部子元素的模板面板，过滤条件对参与聚合的所有后代子元素统一生效。
- 高级 SQL 面板和 KPI 面板忽略过滤条件，按原有逻辑执行。
- 过滤条件引用的属性模板被删除后，该条件自动失效。

### 4.4.6.4 分享携带过滤条件

分享仪表板时，当前的时间范围与过滤条件会作为快照随分享链接一并保存，接收者打开链接即可看到分享者当时的筛选结果。分享链接仅包含一个 token 参数，不包含其他信息。

若仪表板配置了过滤条件，分享弹窗中会显示**锁定过滤条件**选项（默认不勾选）。勾选后，接收端不显示过滤条件入口，接收者不可修改或清除过滤条件。

:::note
快照保存的是分享创建时刻的查看状态，分享者之后修改过滤条件不影响已发出的链接。需要更新筛选结果时，重新创建分享即可。
:::

## 4.4.7 全局仪表板视图

主导航栏中的**仪表板**项打开全局仪表板列表，显示系统中每个元素的所有仪表板。

全局视图的左侧边栏将导航分为六个部分：

- **仪表板：** 系统范围内所有仪表板的主列表。
- **面板：** 所有元素中所有已保存面板的全局列表。
- **仪表板分组：** 您创建的自定义分组，包含加入分组的仪表板。
- **面板分组：** 您创建的自定义分组，包含加入分组的面板。
- **仪表板筛选器：** 仪表板列表的已保存筛选配置。
- **面板筛选器：** 面板列表的已保存筛选配置。

仪表板列表显示以下列：

| 列 | 说明 |
|---|---|
| **名称** | 仪表板名称 |
| **描述** | 可选描述 |
| **模板** | 该仪表板是否从模板创建 |
| **分类** | 分配给该仪表板的分类标签 |

工具栏提供搜索字段、导出列表的 CSV 下载按钮以及列表偏好设置齿轮。

在全局视图中，您可以：

- 按分类**搜索和筛选**以在整个层级中查找仪表板。
- 直接**打开**任意仪表板。
- 无需先导航到元素即可**编辑**或**删除**仪表板。

此视图对于机群级监控特别有用——查找某地区所有电表的仪表板，或查看某站点所有生产线仪表板——无需遍历资产树。
