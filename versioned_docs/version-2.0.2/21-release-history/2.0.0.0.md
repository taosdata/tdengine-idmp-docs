**发布时间：2026-07-17**

## 亮点

1. IDMP 2.0 免费版发布：本版本内置 CLS 许可管理模块，提供 All-in-One 安装包下载，一键安装 TDengine 即可自动申请并激活免费许可；免费版与商业版在功能、性能上完全一致，可通过年度续期长期免费使用，仅在测点数量上有明确限制。
2. AI 能力大幅提升：动作类型新增 AI Agent 支持，实时分析触发后可由智能体自主判断并自动化执行；AI Function 支持从任意页面添加并自动填充作用范围，页面可直接上传 SKILL 文件；AI Chat 支持斜杠命令快速调用 Skill；新增 send_im_message 工具，AI 报告可一键推送到飞书/Telegram/微信；配套新增 Agentic AI 连接管理，统一管理 AI 连接。
3. 可视化与分析能力增强：AI 推荐面板新增直方图、蜡烛图、热力图三类图表；分析工作台新增注解功能，AI 解读内容可一键保存为面板注解，PDF 报告导出更完整；面板模板支持命名模式自定义；仪表板新增时钟、计时器等时间类小组件，满足监控大屏与日常看板需求。
