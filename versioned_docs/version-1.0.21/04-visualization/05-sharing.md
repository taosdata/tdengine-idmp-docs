# 4.5 分享面板与仪表板

TDengine IDMP 提供内置分享机制，可生成面板和仪表板的限时链接。分享链接让接收方无需登录即可以只读方式查看分享时的面板或仪表板状态。

## 4.5.1 分享面板

分享面板的步骤：

1. 以查看模式打开面板（点击任意面板卡片上的**查看**，或导航到已打开的面板）。
2. 点击查看模式工具栏中的**分享**按钮。
3. 弹出对话框，包含**有效时长**字段。输入数字并选择单位：**分钟**、**小时**或**天**。
4. 点击**提交**。链接生成后自动复制到剪贴板，如有需要也可从显示的字段中手动复制。

分享链接会捕获当前时间范围和面板状态。接收方打开链接后，将看到创建链接时所设定时间范围的面板数据。

分享链接具有**时效性**：在所选时长后过期。过期后，链接将返回访问被拒绝的响应。因此，分享链接适用于短期通信（向同事发送图表、附在报告中、粘贴到聊天中），不适合作为永久引用。

## 4.5.2 分享仪表板

仪表板支持与面板相同的分享机制。分享仪表板的步骤：

1. 以查看模式打开仪表板。
2. 点击仪表板工具栏中的**分享**按钮。
3. 复制生成的链接。

链接让接收方以只读方式查看仪表板，保留生成链接时的时间范围和面板布局。

## 4.5.3 将面板下载为图片

除链接分享外，任何面板均可下载为 PNG 图片：

1. 以查看模式打开面板。
2. 点击工具栏中的**保存为图片**按钮。
3. 浏览器将当前图表下载为 PNG 文件。

下载的图片会捕获当前渲染的图表——可见时间范围、所有序列、图例和边界线——无需任何 IDMP 访问权限即可嵌入报告、演示文稿或文档中。

## 4.5.4 在新窗口中打开面板

对于并排比较或多显示器场景，任何已保存的面板都可以在独立浏览器窗口中打开。有两种方式：

- **从面板标签页：** 将鼠标悬停在面板卡片上，点击 **⋮** → **在新窗口打开**。
- **从查看模式：** 点击查看模式工具栏中的**在新窗口打开**按钮。

面板将在新浏览器窗口的查看模式中打开，拥有独立的工具栏和时间范围控件。此窗口独立运行：您可以在新窗口中设置与主标签页不同的时间范围。

## 4.5.5 管理分享链接

所有已生成的分享链接可在 **管理后台** → **分享管理** 页面集中查看和维护。列表以分页形式展示每个分享链接的关键信息：

- **资源名称：** 链接指向的面板或仪表板名称。
- **资源类型：** 面板、仪表板、面板模板或仪表板模板。
- **元素：** 资源所属的元素。
- **过期时间：** 链接失效的时刻。
- **状态：** 启用或已禁用。
- **计数：** 链接被访问的次数。

出于安全考虑，列表中的分享令牌以掩码（`••••••••`）显示。如需查看明文，点击令牌列的**查看**按钮。若管理员在安全配置中为分享令牌启用了二次验证，查看明文时会要求输入二次密码或完成多因子验证。

页面顶部提供筛选与操作入口：

- **资源类型 / 元素筛选：** 左上角的两个下拉框可按资源类型或元素过滤列表。
- **刷新：** 重新加载最新的分享链接列表。
- **列配置：** 控制表格中显示哪些列。

在每一行的 **⋮** 菜单中，可对该分享链接执行以下操作：

- **查看详情：** 打开详情对话框，展示分享地址、有效时长、过期时间、状态和访问次数。对话框中的分享地址可一键复制；复制时会获取完整链接，若已启用二次验证则需先完成验证。
- **修改过期时间：** 通过日期选择器设定新的到期时刻。所选时刻必须晚于当前时间。
- **启用 / 禁用：** 禁用后链接立即失效，接收方将无法访问；重新启用即可恢复。
- **删除：** 永久移除该分享链接。
