# 4.2.19 KPI 报表

## 4.2.19.1 概述

**KPI 报表**是一种以表格（而非图表）形式展示关键绩效指标的特殊面板类型。它按资产层级以树形结构在首列展示元素，其余每一列展示一个 KPI 子属性或计算结果，并可按统计周期进行对比（环比 / 同比）。

与基于 ECharts 的图表面板不同，KPI 报表渲染为一张可逐层展开的层级表格，适合在一张表中纵览多个资产、多个指标及其周期对比。

## 4.2.19.2 数据来源

KPI 报表的数据列来自 [KPI 属性](../../03-data-modeling/02-attributes.md)。每个 KPI 属性包含若干子属性（聚合函数 × 统计周期的组合），这些子属性即为可选的数据列。

## 4.2.19.3 配置列

1. 在左侧边栏选择**周期**（小时 / 天 / 周 / 月 / 季），用于筛选可添加的 KPI 子属性。
2. 在 **KPI 指标**选择器中，双击或点击「添加到列定义」将子属性加入列。
3. 在「列定义」表中逐列配置：

| 配置项           | 说明                                                 |
| ---------------- | ---------------------------------------------------- |
| **列名**   | 列标题，可双击表头就地编辑                           |
| **表达式** | 该列的数据来源表达式（数据列自动生成；计算列可自定义） |
| **统计周期** | 该列的时间聚合周期                                   |
| **相对周期** | 相对周期偏移，如本期 / 上期等                        |
| **对比**   | 可选环比（MoM）或同比（YoY），在同一单元格附加对比值 |
| **聚合**   | 子元素聚合方式：求和 / 平均 / 最小 / 最大 / 计数 / 无 |
| **显示**   | 控制该列是否显示                                     |

也可点击「添加计算列」，用表达式引用其他列进行二次计算。

## 4.2.19.4 对比展示

为列启用对比后，单元格会在主值旁附加对比结果：

| 选项           | 说明                                 |
| -------------- | ------------------------------------ |
| **对比展示** | 以**百分比**或**差值**形式展示对比结果 |
| **上涨颜色** | 数值上升时的颜色（默认红色）         |
| **下跌颜色** | 数值下降时的颜色（默认绿色）         |

## 4.2.19.5 面板选项

在右侧属性面板中可配置：

| 选项                                       | 说明                                           |
| ------------------------------------------ | ---------------------------------------------- |
| **顶部过滤器**                       | 查看面板时顶部展示的过滤器：不显示 / 时间周期 / 资产结构 |
| **汇总行**                           | 可选的表尾汇总行，并可自定义其标签             |
| **表头样式 / 数据行样式 / 资产结构列样式** | 字体、字号、文字颜色、背景色等                 |
| **表头行高 / 数据行高 / 表格外边距 / 报表背景色** | 表格尺寸与背景                                 |
| **合并表头**                         | 选中相邻多列后合并其表头，用于分组展示         |
| **单元格样式**                       | 右键数据单元格可单独设置 / 清除其样式          |

## 4.2.19.6 适用场景

**多资产 KPI 汇总。** 在一张报表中纵览全厂各产线的日产量、能耗、良率等 KPI，并按月对比（同比 / 环比），快速定位异常资产。

**周期对比看板。** 为每个 KPI 列启用环比，以百分比展示本周期相对上一周期的变化，红涨绿跌一目了然。
