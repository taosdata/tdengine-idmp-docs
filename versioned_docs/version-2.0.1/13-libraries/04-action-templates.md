# 13.4 动作模板

**动作模板**定义可复用的自动化动作，供[实时智能分析](../07-real-time-analysis/index.md)在触发条件满足时调用。例如，当某台配电变压器的分析输出平均电压超过阈值时，自动向运维群发送一条告警通知。将动作沉淀为模板后，多个分析可引用同一模板，并在各自的实时分析中对运行参数做局部调整，而不影响模板本身。

系统为每种动作类型预置一个动作模板，共四种：

| 动作模板 | 动作类型 | 用途 |
|---|---|---|
| **通知任务** | 通知（NOTIFICATION） | 通过联系方式发送告警通知 |
| **飞书任务** | 飞书（FEISHU） | 在飞书中创建任务并指派处理人 |
| **IDMP 任务** | IDMP（IDMP） | 在本系统内对元素 / 事件等执行操作 |
| **智能体任务** | 智能体（AGENT） | 调用 AI Function 做智能诊断或处理 |

动作模板在**基础库 → 动作模板**中管理。

:::note
系统为每种动作类型预置一个动作模板。你在列表中**查看与编辑**各模板的配置字段（动作类型与模板名称由系统定义）。
:::

## 13.4.1 动作模板列表

列表显示所有动作模板，包含以下列：

| 列 | 说明 |
|---|---|
| **名称** | 动作模板名称 |
| **类别** | 分配给模板的类别标签 |
| **描述** | 可选描述 |

:::note
为避免误用，列表**不展示动作类型**列——每个模板的用途由其名称与描述体现。
:::

点击模板名称（或行上 **⋮** 菜单中的**查看 / 编辑**）可查看或编辑模板配置。

## 13.4.2 动作模板配置

进入动作模板的编辑页后，先填写所有类型共用的**基础信息**，再按该模板的动作类型编辑对应的配置字段。这里的配置值是各分析引用该模板时的**默认值**。

### 基础信息字段

| 字段 | 说明 |
|---|---|
| **名称** | 动作模板名称（系统定义，只读）。 |
| **类别** | 用于组织和筛选模板的可选类别标签，支持内联创建新标签。类别类型为**动作模板**。 |
| **描述** | 可选的自由文本描述，用于说明该动作的用途。在分析中选择模板时，描述以提示形式展示在选择框旁。 |

### 通知任务配置

| 字段 | 说明 |
|---|---|
| **联系方式** | 发送通知所使用的联系方式（Contact Point），从系统已定义的联系方式列表中单选。联系方式本身携带通道类型（邮件 / 飞书 / 企业微信等），决定通知通过哪个渠道发出。 |
| **最小通知间隔（分钟）** | 同一分析对同一联系方式连续两次发送通知的最小时间间隔，默认 10 分钟。用于在条件持续满足时限制通知发送频率，防止通知过载。 |
| **通知标题** | 通知的标题。支持 `{...}` 占位符（见 [13.4.3](#1343-文本占位符)），留空时使用系统按界面语言提供的默认标题。 |
| **通知内容** | 通知的正文。支持 `{...}` 占位符，运行时替换为分析所属元素的实际信息和输出属性值。 |

### 飞书任务配置

| 字段 | 说明 |
|---|---|
| **飞书 App ID** | 飞书开放平台自建应用的 App ID。 |
| **飞书 App Secret** | 对应自建应用的 App Secret。查看态以掩码 `******` 展示。 |
| **任务处理人** | IDMP 用户列表中的一个或多个处理人。执行时按用户邮箱解析为飞书 `open_id` 并加为任务成员；无法匹配邮箱的用户会被跳过。 |
| **标题** | 飞书任务的标题。支持 `{...}` 占位符。 |
| **内容** | 飞书任务的描述内容。支持 `{...}` 占位符。 |
| **动作描述（JSON）** | 附加到飞书任务的自由 JSON 负载，留空时视为 `{}`。 |

:::note
App ID 与 App Secret 需在[飞书开放平台](https://open.feishu.cn/app)的自建应用中获取。该应用须具备创建任务、读取用户等相应权限。
:::

### IDMP 任务配置

IDMP 任务向目标对象追加一条注释。

| 字段 | 说明 |
|---|---|
| **对象类型** | 目标对象类型（如元素、事件），作为引用该模板时的默认目标类型。 |
| **注释内容** | 追加到目标对象的注释正文。支持 `{...}` 占位符。 |

:::note
具体的目标对象在分析侧引用模板时选择（见 [13.4.5](#1345-在分析中使用动作模板)）。
:::

### 智能体任务配置

| 字段 | 说明 |
|---|---|
| **AI Function** | 要调用的 AI Function，从系统已注册的 AI Function 列表中单选。 |
| **执行命令** | 传给 AI Function 的自由文本指令，提供额外上下文。支持 `${...}` 占位符，运行时替换为元素上下文（如 `Diagnose the anomaly on ${elementName}`）。 |

:::note
智能体任务执行时会调用 AI Function，系统会自动创建一个用于该任务的 API Key 完成鉴权。请勿在 API Key 列表中删除它，否则智能体任务将无法调用 AI 服务。
:::

## 13.4.3 文本占位符

动作模板中有两处文本支持占位符，语法不同，请勿混用：

**通知标题 / 通知内容 / 飞书任务标题 / 飞书任务内容 / IDMP 注释内容** 使用花括号 `{...}` 语法，运行时替换为分析所属元素的实际信息与本次实时分析的输出属性值：

| 占位符 | 替换为 |
|---|---|
| `{elementName}` | 触发动作的实时分析所属元素的名称 |
| `{elementPath}` | 该元素在资产树中的完整路径 |
| `{analysisName}` | 触发动作的分析名称 |
| `{属性名}` | 本次实时分析对应输出属性的计算值，例如 `{avg_voltage}` |

**智能体任务的执行命令** 使用 `${...}` 语法（与触发条件表达式中的属性引用一致），运行时替换为元素上下文，例如 `${elementName}`。

未能解析的占位符在最终文本中保持原样。

**默认通知标题**（按界面语言）形如：

```text
分析动作触发通知：{analysisName}
```

**默认通知内容**（按界面语言）形如：

```text
1. 元素名称: {elementName}
2. 元素路径: {elementPath}
3. 关联的分析: {analysisName}
```

:::tip
分析的**触发条件**表达式使用 `attributes['属性名']` 语法引用输出属性（见[在分析中配置动作](../07-real-time-analysis/08-actions.md)），与上述文本占位符语法不同。
:::

## 13.4.4 编辑动作模板

要编辑动作模板，点击列表中的名称，再点击**编辑**，修改配置字段后保存。修改只影响**此后引用该模板的分析所取的默认值**；已保存分析的运行参数由其自身的快照与配置覆盖决定，不会被追溯修改（见 [13.4.5](#1345-在分析中使用动作模板)）。

:::note
动作模板由系统预置，其动作类型与名称由系统定义。
:::

## 13.4.5 在分析中使用动作模板

动作模板配置完成后，在分析创建表单的第 5 段**动作**中引用。每条动作规则由一个**触发条件**和一个引用的**动作模板**组成；条件满足时执行该模板对应的动作（触发条件留空时视为无条件、每次触发都执行）。引用模板后，可在分析中对模板的配置做局部调整，调整仅作用于当前分析，不回写模板：

- **通知任务**：可重选联系方式、调整最小通知间隔、修改标题和内容。
- **飞书任务**：可修改 App ID / App Secret、处理人、标题、内容与动作描述。
- **IDMP 任务**：可重选对象类型、指定具体目标对象、修改注释内容。
- **智能体任务**：可重选 AI Function、修改执行命令。

完整的分析侧配置与运行时行为说明，请参见[在分析中配置动作](../07-real-time-analysis/08-actions.md)。
