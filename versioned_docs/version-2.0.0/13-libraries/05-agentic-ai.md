# 13.5 Agentic AI

**Agentic AI** 是 IDMP 中管理 AI Agent 可复用能力的中央入口，涵盖 **Skills（技能）** 和 **MCP 模板** 两大类资源。管理员在此处定义和维护组织级别的 AI 能力，用户则在[个人设置](../14-administration/08-profile-settings.md)中基于这些模板配置自己的 MCP 连接。

Agentic AI 在**基础库 → Agentic AI** 中管理，包含以下子页面：

| 子页面       | 说明                                                             |
| ------------ | ---------------------------------------------------------------- |
| **技能**     | 管理和配置 AI Agent 可使用的技能文件                             |
| **MCP 模板** | 管理 MCP 服务器模板，用户在个人设置中基于模板配置自己的 MCP 连接 |

## 13.5.1 Skills（技能）

Skills 页面用于上传和管理 AI Agent 可使用的技能文件。技能定义了 Agent 在执行特定任务时的行为模式、工具调用和知识上下文。上传后的技能可由 AI 服务端加载，供所有已连接的 AI Agent 按需调用。

### 13.5.1.1 技能列表

列表显示所有已上传的技能文件，包含以下信息：

| 列         | 说明                       |
| ---------- | -------------------------- |
| **名称**   | 技能文件名称               |
| **描述**   | 技能的功能说明             |
| **类型**   | 技能的分类类型             |
| **已启用** | 是否已激活，可通过开关控制 |

### 13.5.1.2 上传技能

点击 **+** 上传新技能文件。上传后技能将出现在列表中，可通过启用开关控制其是否对 AI Agent 可用。

## 13.5.2 MCP 模板

MCP 模板定义了 MCP 服务器的连接规范，包括连接类型、地址、请求头和用户可配置的变量。管理员创建模板后，用户在[个人设置的 Agent 标签页](../14-administration/08-profile-settings.md#1485-agent)中基于模板填写变量值，即可完成个人 MCP 连接的配置。

### 13.5.2.1 MCP 模板列表

列表显示所有已定义的 MCP 模板，包含以下列：

| 列           | 说明                                      |
| ------------ | ----------------------------------------- |
| **模板名称** | MCP 模板的唯一名称                        |
| **描述**     | 模板的用途描述                            |
| **类型**     | 连接类型：`HTTP`、`SSE` 或 `命令 (stdio)` |
| **变量数**   | 模板中定义的需用户配置的变量数量          |
| **已启用**   | 是否已激活，可通过开关控制                |

点击行末的 **⋮** 菜单可编辑或删除模板。

### 13.5.2.2 创建 MCP 模板

点击 **+** 创建新 MCP 模板。填写以下字段：

| 字段                 | 说明                                             |
| -------------------- | ------------------------------------------------ |
| **模板名称**（必填） | 模板的唯一名称。创建后不可修改。                 |
| **描述**             | 模板的可选描述。                                 |
| **类型**（必填）     | 连接类型，可选 `HTTP`、`SSE` 或 `命令 (stdio)`。 |

根据所选类型，配置对应的连接参数：

**HTTP / SSE 类型：**

| 字段               | 说明                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------- |
| **URL**（必填）    | MCP 服务器的连接地址。支持 `${varName}` 占位符引用变量。                                    |
| **请求头**（可选） | JSON 格式的 HTTP 请求头，例如 `{"Authorization": "Bearer xxx"}`。支持 `${varName}` 占位符。 |

**命令 (stdio) 类型：**

| 字段             | 说明                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| **命令**（必填） | MCP 服务器的启动命令，例如 `npx @scope/server-foo`。支持 `${varName}` 占位符。 |

### 13.5.2.3 变量定义

模板中可以定义变量，由用户在配置个人 MCP 连接时填写具体值。每个变量包含：

| 字段       | 说明                                                 |
| ---------- | ---------------------------------------------------- |
| **变量名** | 变量的标识符，在 URL 和请求头中通过 `${变量名}` 引用 |
| **说明**   | 变量的用途描述，帮助用户理解应填写的值               |

变量数大于 0 的模板在列表中会显示对应的数量标识。用户在个人设置中配置 MCP 连接时，系统会提示填写所有变量的值。变量数为 0 的模板视为"自动可用"，无需用户额外配置。

### 13.5.2.4 编辑与删除

- **编辑：** 点击行末 **⋮** 菜单中的 **编辑**，可修改除名称外的所有字段。
- **删除：** 点击行末 **⋮** 菜单中的 **删除**，确认后模板将被移除。

### 13.5.2.5 使用 MCP 模板

MCP 模板由管理员统一维护。用户登录后在**个人设置 → Agent** 标签页中，可看到所有已启用的模板，并根据自身需要填写变量值来完成 MCP 连接的配置。具体操作参见[第 14.8.5 节 Agent 标签页](../14-administration/08-profile-settings.md#1485-agent)。
