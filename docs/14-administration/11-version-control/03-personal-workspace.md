# 14.11.3 个人工作空间

在 **Review Required** 或 **E-Signature** 模式下，每个用户拥有独立的**个人工作空间**。
个人工作空间确保用户未审核的修改不会影响公共视图，也不会被其他用户看到。

## 什么是个人工作空间？

个人工作空间是系统为每个用户自动创建的独立 Git 分支。在审核模式下：

- 用户的所有修改在个人分支上进行
- 其他用户看不到这些修改
- 修改只有通过 MR/PR 审核并合并后，才对全员可见

## 初始化个人工作空间



### 触发时机

个人工作空间采用**懒创建**策略： 只在用户首次编辑受版本控制的对象时自动触发。

例如当用户执行以下任一操作时，系统检测到工作空间未初始化，会自动触发创建：

- 新建元素、模板、面板等
- 修改元素属性、分析配置等
- 删除 UOM，添加分类等

### 初始化流程

1. 用户点击"保存"或"确认"按钮
2. 系统检测到个人工作空间未初始化
3. 弹出确认对话框："检测到当前工作区尚未初始化，是否立即开始初始化？"
4. 用户确认后，全屏显示加载动画
5. 系统在后台创建个人分支、复制数据
6. 初始化完成后，右上角显示"工作区已就绪"通知
7. 用户可正常保存修改

![个人工作空间初始化确认](../images/enable-version-control.png)

> 初始化期间，用户可以在页面中继续编辑表单，但点击保存时系统会提示"工作区尚未准备好"。

### 状态指示

初始化过程中，右上角头像旁边会显示工作空间状态徽标：

- **初始化中**：旋转图标 + "初始化中 XXs"
- **初始化失败**：红色感叹号 + 错误摘要，可点击重试
- **就绪**：徽标自动隐藏

![工作空间状态徽标](../images/enable-version-control.png)

## 删除个人工作空间

如果用户需要回到公共工作空间（admin 视图），可以手动删除个人工作空间。

1. 点击右上角用户头像
2. 在下拉菜单中选择 **删除个人工作空间**
3. 输入审计原因确认
4. 页面自动刷新，回到公共视图

![删除个人工作空间](../images/enable-version-control.png)

:::warning 注意
删除个人工作空间会丢失所有未提交的修改。请确保已提交或不需要这些修改后再执行删除。
:::

## 从 Main 同步

当其他用户的 MR/PR 被合并后，您的个人工作空间可能落后于 main 分支。在变更列表页右上角有**同步按钮**：

- 按钮显示 main 分支落后的提交数
- 点击按钮将 main 的最新内容合并到个人工作空间
- 同步后，您可以看到其他用户已合并的修改

![从 Main 同步](../images/enable-version-control.png)

## 工作空间生命周期

```text
用户首次修改 → 自动创建个人工作空间 → 修改在个人分支上进行
                                          ↓
                              Check-In → 提交 MR/PR → 审核合并
                                          ↓
                              合并后个人工作空间保留（可能有未提交的修改）
                                          ↓
                              用户可手动删除个人工作空间回到公共视图
```
