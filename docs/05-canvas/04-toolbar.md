# 5.4 工具栏

工具栏位于组态编辑器顶部，提供钢笔、铅笔、放大镜等画图工具，格式刷、连线起点、终点、类型、线宽等样式工具，视图比例等视图控制，默认配置，以及导入导出、保存等操作。

## 5.4.1 钢笔

1. 开始：单击左键
2. 暂停：单击右键 或 enter
3. 结束：esc
4. 闭合/取消闭合：enter

## 5.4.2 铅笔

1. 开始：连续拖动左键
2. 暂停：释放左键
3. 结束：esc
4. 闭合/取消闭合：enter

## 5.4.5 格式刷

格式刷用于将一个图元或线条的样式快速复制到其他图元上，批量统一画面外观。

使用步骤：

1. 在画布上选中恰好一个图元、线条或文字（多选、框选或未选中时按钮不可用）。
2. 点击工具栏中的**格式刷**按钮，进入刷取模式：按钮高亮，画布光标变为复制样式。
3. 点击要应用样式的目标图元，格式即被复制，刷取模式自动退出；目标图元保持选中，可再次点击格式刷，以它为新的格式源继续传播样式。
4. 按 `Esc` 或再次点击按钮可随时退出刷取模式；点击画布空白处不会退出。

可复制的样式分为 5 组，按源与目标的类型自动裁剪：

| 样式组 | 内容 | 生效条件 |
| --- | --- | --- |
| 描边通用 | 颜色、线型、线宽、线条渐变、线帽与拐角、悬停/选中色、透明度、阴影、滤镜等 | 形状与线条互相刷均生效 |
| 填充与边框 | 背景类型（纯色/线性/径向渐变）、背景色、边框、圆角等 | 仅形状刷形状时生效 |
| 箭头 | 起点/终点箭头样式、大小、颜色 | 仅线条刷线条时生效 |
| 文字 | 字体、字号、文字颜色、对齐、下划线、删除线等 | 仅目标包含文字时生效 |
| 动画 | 图元动画、线条动画及播放参数 | 仅同类型之间生效（形状→形状、线条→线条） |

覆盖为全量覆盖：源图元上未显式设置的样式，会清除目标图元上的同名设置，使其回退默认外观；刷取操作可通过撤销（`Ctrl/Cmd + Z`）恢复。

## 5.4.6 连线起点

设置连线起点的箭头样式。点击图标弹出下拉菜单，可在多种箭头样式中选择，包括：无箭头、三角形、菱形、圆形、向下折线、向上折线、实心三角形、实心菱形、实心圆形、短线段。

- 设置后会作为画布的默认起点箭头样式应用于后续新绘制的连线。
- 若已选中一条或多条连线，则同时修改这些选中连线的起点箭头。

## 5.4.7 连线终点

设置连线终点的箭头样式，可选项与起点箭头相同。设置后会作为画布默认值，并同步应用到当前选中的连线。

## 5.4.8 连线类型

设置画布默认的连线类型。鼠标悬停展开下拉菜单，可选：

- **曲线**：平滑的贝塞尔曲线。
- **线段**：自动转折的折线段。
- **直线**：两点之间的直线。
- **脑图曲线**：脑图风格的曲线。

切换后影响后续使用钢笔/铅笔绘制的连线类型。

## 5.4.9 线宽

设置画布默认的连线线宽，鼠标悬停后弹出数字输入框，输入大于等于 1 的整数值。设置后会作为新绘制连线的默认线宽，若已选中连线，则同步修改选中连线的线宽。

## 5.4.10 视图比例

显示并调整画布的缩放比例。点击图标后弹出操作面板：

- **缩小**：每次缩小 10%。
- **放大**：每次放大 10%。
- **窗口大小**：自动适配画布内容到当前窗口（fitView）。
- **重置**：恢复到 100% 并居中视图。

## 5.4.11 自动锚点

开启后，连线连接到图元时会自动吸附至最近的锚点位置；关闭后需要手动连接到指定锚点。按下快捷键 `Alt` 可临时切换该状态。

## 5.4.12 禁用锚点

开启后，画布将隐藏所有图元的锚点，禁止绘制连线，常用于查看或防止误操作；再次点击可恢复显示锚点。

## 5.4.13 返回列表

返回到组态列表页。当画布存在未保存的修改时按钮不可用，请先保存或撤销修改后再返回。

## 5.4.14 保存

保存当前组态的所有修改。保存时会生成画布缩略图，并将画布数据持久化到服务器。仅在画布有改动时按钮可点击。

## 5.4.15 撤销修改

放弃当前所有未保存的修改，恢复到上次保存时的状态。仅在画布有改动时按钮可点击。

## 5.4.16 导入

从本地文件导入组态数据，根据文件后缀名自动识别格式，支持 `.json`、`.svg`、`.zip`、`.vsdx`、`.dxf`。

### SVG 文件导入

支持将任意 SVG 矢量图形文件导入为临时图元。受当前解析能力限制，存在以下不支持的场景：

1. SVG 中复杂的渐变、CSS3 动画以及内嵌 JS 暂不支持，目前仅能较好地解析类似单线图风格的 SVG。
2. SVG 的 CSS 优先级被简化为合并操作处理，可能与浏览器原生渲染存在差异。
3. 不支持嵌套层级较深的 `<tspan>` 标签，推荐使用 AI 等工具先将 `<text>` 转换为 `<path>` 路径再导入。
4. 暂不支持 `<use>` 复用标签。
5. `<path>` 标签的位置计算可能存在偏差，导致由 `<path>` 转换出的图形不便单独选中。

### JSON 文件导入

支持导入符合 meta2d.js 核心库数据结构的 JSON 文件，其中 `pens` 数组的数据结构必须正确，才能被正确绘制。

### ZIP 文件导入

用于一次性导入画布数据及其引用的图片素材：

1. 仅会检查压缩包中是否包含 JSON 文件，如有多个，只会使用第一个 JSON 文件作为画布数据。
2. 压缩包内的所有图片类型文件会被自动上传到当前用户的私有图元文件夹下，并替换 JSON 中的图片引用路径。

### VSDX 文件导入

支持导入 Microsoft Visio 绘图文件。对于较为复杂的文件（例如 Visio 中包含无法解析的二进制文件、嵌套文件等）的解析和部分绘制指令的兼容性存在一定局限，可能出现少部分图形表现不一致；另外对主题颜色功能的支持尚不完善，可能出现颜色不一致的情况，用户可在解析后手动调整颜色。

### DXF 文件导入

支持导入 AutoCAD 图纸交换格式（DXF）文件。解析库虽已支持 CAD 的大部分元素，但对部分类型（例如标注类型和部分填充类型）目前还不支持，另外对 BLOCK 多层嵌套类型的解析也存在问题。

## 5.4.17 导出

将当前画布导出为本地文件，可选格式：

- **JSON**：导出符合 meta2d.js 数据结构的完整画布数据，可在其他组态中通过导入直接复用画面。
- **PNG**：导出画布的位图截图，文件名为当前组态的名称。
- **SVG**：导出画布的矢量图，文件名为随机字符串。

## 5.4.18 刷新

强制刷新画布的实时数据，立即向后端拉取最新数据并重新渲染图元。

## 5.4.19 锁定

切换画布的锁定状态，三种状态循环切换：

1. **编辑**：默认状态，可以自由编辑画布中的所有图元。
2. **预览**：图元不可编辑，但保留交互（点击事件、动画等），用于预览运行效果。
3. **锁定**：图元不可编辑、不可移动，仅可查看。

:::note
图元上配置的交互（事件、动画等）在**预览**或**锁定**状态下执行。编辑态下点击图元用于选中与编辑，不会触发交互，属正常现象。

双击趋势弹窗、右键菜单与「打开链接」跳转**仅在组态预览页生效**，编辑器内的预览 / 锁定状态均不触发；悬停数值气泡在编辑器内仅**预览**状态显示。详见 [5.8.8 预览态功能](./08-function-points/08-view-mode.md)。
:::

## 5.4.20 默认配置

默认配置将绘图规范——画布、图元、文字、线条的默认样式与编辑器行为——收口为统一配置：设置一次后，新画面、新图元、新连线自动携带该规范，已有画面不受影响。例如团队规范要求"蓝色描边、文字统一 14px、连线统一 2px 实线带终点箭头"，配置一次即可。

点击工具栏中的**默认配置**按钮，在弹出的对话框中切换 5 个页签进行配置：

- **画布**：颜色、网格与标尺、图纸尺寸等新画面的默认值。
- **图元**：描边与填充等新图元的默认样式。
- **文字**：字体等默认文字样式。
- **线条**：样式、箭头等新连线的默认值。
- **编辑器**：缩放范围、交互等个人编辑偏好。该组保存后立即生效于当前编辑会话，不写入画面数据。

默认配置由系统出厂默认与个人覆盖两层构成：个人修改保存在本浏览器中并覆盖出厂默认，存在个人覆盖时按钮右上角会显示标记点；点击**恢复默认值**可清除个人配置，回到出厂默认。

## 5.4.21 属性面板

点击右侧箭头图标可显示或隐藏右侧的图元配置面板，便于在小屏幕上扩大画布的可视区域。
