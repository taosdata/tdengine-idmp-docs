# 5.8.3 设置图元属性值

图元属性值的设置方式有两种：**手动设置**与**绑定属性**。手动设置适合在编辑时确定静态外观、测试联动效果；绑定属性后，采集到的实时数据可以自动驱动图元展示。

## 5.8.3.1 手动设置

图元有很多属性，包括颜色、文本字体、字体颜色、进度等，这些通用属性都可以在外观设置里直接手动进行设置。其中文本、进度值、状态、值四个属性，还可以在事件的触发条件里进行逻辑判断。

## 5.8.3.2 通过事件自动设置

在事件的设置里，可以通过选择"设置图元属性"事件行为来自动控制图元的属性。可以自动控制的属性包括：背景颜色、颜色、文本颜色、文本、X、Y、高度、宽度、可见、进度值、进度颜色、值、状态、旋转、禁用等。事件类型与触发条件的详细说明参见 [5.8.6 设置图元事件](./06-events.md)。

## 5.8.3.3 绑定属性

除事件外，另一种方式是将上述属性与 IDMP 的元素属性进行绑定。绑定变量，能快速实现实时数据动态展示。如下图所示，添加属性绑定，将图元的"文本"绑定到元素"em-1"的电压。当元素电压采集值变化时，图元的文本在刷新数据时，也会跟着实时变化。

:::tip
绑定变量之前，建议先手动输入属性值，测试想要的效果，比如进度条的变化、状态的改变、事件的触发等。等测试达到想要的效果后，再将属性绑定到 IDMP 某个元素的属性。投入生产运营的组态，图元的属性一定是与元素的属性进行绑定了的。
:::
