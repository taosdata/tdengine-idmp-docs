# 5.8.8 预览态功能

组态画面以查看方式打开后即处于预览态，此时无需额外配置即可使用以下内置能力：

- **双击趋势弹窗**：双击已绑定数据的图元，弹出可拖拽的趋势图弹窗，查看该测点的历史曲线。时间范围继承画布当前范围，最多可同时打开 10 张，同一图元去重。
- **悬停数值气泡**：鼠标悬停在已绑定的图元上时，显示该测点的路径、时间与当前值，画面保持简洁、数据随查随有。
- **添加到分析工作台**：预览态下右键已绑定数据的图元，可将其推送到分析工作台，支持多选批量推送。选择**添加到分析工作台**在新标签页中打开；选择**添加到独立分析工作台**则在当前页以弹框形式打开独立的分析工作台。
- **查看面板详情**：右键面板图元并选择**查看详情**，在新标签页中打开该面板的预览页。

:::note
以上能力仅在预览态生效。在编辑器内，即使通过工具栏切换到**预览**或**锁定**状态，也不会触发双击趋势弹窗、右键菜单与「打开链接」跳转；其中仅**预览**状态显示悬停数值气泡。详见 [5.4.19 锁定](../04-toolbar.md#5419-锁定)。
:::
