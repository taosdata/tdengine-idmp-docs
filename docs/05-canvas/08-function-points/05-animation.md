# 5.8.5 设置图元动画

IDMP 内置很多种图元动画效果，也容许逐帧自定义动画，让监控画面生动直观。

## 5.8.5.1 添加动画

给图元添加动画，设置动画时长、动画效果、循环次数、下个动画 tag、是否自动播放、是否保持动画状态。

## 5.8.5.2 内置动画

内置动画包括：无、上下跳动、左右跳动、心跳、成功、警告、错误、炫耀、旋转、自定义。

## 5.8.5.3 自定义动画

通过新增动画帧，逐帧自定义动画。

## 5.8.5.4 触发方式

除配置自动播放外，动画还可以由事件触发：事件行为支持执行动画、暂停动画、停止动画。例如在"图元属性值变化"事件中配置执行动画，即可实现数据变化时播放动画的效果，参见 [5.8.6 设置图元事件](./06-events.md)。
