# 5.8.1 设置组合图元

在画布中选中多个图元，点击鼠标右键，选择**组合**，即可将多个图元拼接组合为一个组合图元。组合后可以按任意想要的方式组织画面，有利于图元复用。

## 5.8.1.1 操作步骤

1. 在画布中框选或按住 `Ctrl` 依次点选多个图元。
2. 点击鼠标右键，在右键菜单中选择**组合**，所选图元即组合为一个组合图元。
3. 组合后的图元可以作为一个整体拖动、缩放；双击可进入组合内部，继续对任意子图元进行图元的处理操作，按 `Esc` 退出子图元编辑。

:::warning
取消组合前请确认组合图元的数据已不再需要：右键菜单选择**取消组合**（快捷键 `Ctrl/Cmd + Shift + G`）时，系统会提示取消组合将丢失组合图元的数据。
:::
