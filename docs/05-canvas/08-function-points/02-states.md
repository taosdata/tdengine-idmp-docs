# 5.8.2 设置图元状态

普通图元与组合图元都可以设置状态。状态由"条件 + 外观"构成：条件对某个图元属性的绑定值求值，命中后图元自动切换到对应外观——普通图元改变颜色、播放动画，组合图元切换显示对应的子图元。例如开和关、风机的转动与停止，可以配置为一个组合图元的两个状态；红、黄、绿三色报警灯，也可以作为一个组合图元的三个状态随采集值自动切换。

## 5.8.2.1 普通图元：状态配置

普通图元通过右侧配置面板**外观**中的状态配置模块添加状态：

1. 选中图元，切换到**外观**，展开状态区块，点击**添加状态**。
2. 在弹出的「状态配置-普通图元」对话框中配置以下内容：

| 配置项 | 说明 |
| --- | --- |
| 状态名称 | 状态的显示名称 |
| 图元属性 | 条件求值的驱动属性，默认为「值」，可改为其他已绑定的属性 |
| 条件 | 支持大于、大于等于、小于、小于等于、等于、不等于、介于；选择「介于」时输入上下界 |
| 属性值 | 条件的比较值 |
| 作用目标 | 状态命中后颜色写入的目标，可选背景颜色、颜色、文本颜色 |
| 状态颜色 | 命中后写入作用目标的颜色 |
| 动画 | 命中后播放的动画，可选无或图元动画（仅当图元已配置动画时可选） |

3. 点击**确定**保存。状态列表中可随时编辑或删除已有状态；状态值重复时，需修改后保存。

## 5.8.2.2 组合图元：组合为状态

选中两个或更多图元，点击鼠标右键，选择**组合为状态**，即可将它们组合为一个带状态的组合图元：组合内的每个子图元对应一个状态，状态命中时画面切换显示对应的子图元。

组合图元的状态同样在**外观**的状态配置模块中维护，对话框标题为「状态配置-组合图元」：驱动属性默认为「状态」，可配置各状态的名称、条件与动画，但没有作用目标与状态颜色（外观切换由子图元呈现）。状态与子图元一一对应，不支持单独增加或删除状态。

## 5.8.2.3 驱动状态切换

状态条件对「图元属性」的最新绑定值自动求值，因此：

1. **属性绑定**：将驱动属性（如「值」）绑定到 IDMP 元素的属性，采集值变化时自动匹配条件、切换状态，绑定方法参见 [5.8.3 设置图元属性值](./03-property-values.md)。
2. **事件驱动**：通过"设置图元属性"事件行为修改图元的状态属性，参见 [5.8.6 设置图元事件](./06-events.md)。
