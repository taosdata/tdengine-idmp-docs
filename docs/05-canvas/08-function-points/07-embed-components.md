# 5.8.7 嵌入组件

组态画布不仅是"示意图"，还可嵌入多种展示组件，让画面直接呈现实时视频、外部网页、动态数据表格与刻度量尺等内容。以下介绍可嵌入画布的组件类型；将已有分析面板嵌入画布的方法参见 [5.2.3 面板图元](../02-symbol-library.md)。

## 5.8.7.1 视频

视频图元用于接入实时视频流，在画面内直接查看现场画面。

## 5.8.7.2 网页（iframe）

网页图元用于嵌入外部网页内容，在画布中呈现外部系统页面。

## 5.8.7.3 表格

表格图元支持对多个属性实时刷新，将若干元素的关键属性排列为一张动态表，常用于告警清单、设备状态一览、班组分项读数等场景。

## 5.8.7.4 量尺

量尺图元用于在画面中放置刻度标尺，通过配置刻度间隔、方向、刻度位置、显示刻度值与显示当前值等属性，直观呈现数值的刻度指示。
