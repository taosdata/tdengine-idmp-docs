# 5.3 画布

## 5.3.1 设置画布属性

1. **默认颜色**：预先设置默认颜色，拖拽到画布的图元（基础图形、文字、icon）自动统一默认颜色。
2. **背景**：背景图片、背景颜色
3. **网格**：背景网格、网格颜色、网格大小、网格角度
4. **标尺**：开启标尺、标尺颜色
5. **PC 端自动缩放**：控制画面打开时以及窗口尺寸变化时的显示比例，开关随画面保存。
   - 开启：画面随窗口大小自动缩放，尽量完整地显示在可视区域内。
   - 关闭：画面按 100% 的原始尺寸显示。未超出窗口的方向居中，超出的方向从左上角开始显示，其余部分通过拖动画布查看。关闭后窗口尺寸变化时，预览态会重新对齐画面，编辑器内则保留当前的缩放与平移。

:::tip
「PC 端自动缩放」默认关闭，升级前创建的画面同样按 100% 显示。需要画面随窗口自动缩放时，在编辑器右侧的画布属性中开启该开关并保存；希望新建画面默认开启，可在[默认配置](./04-toolbar.md#5420-默认配置)的「画布」页签中设置。
:::

## 5.3.2 设置画布布局

选择多个图元时，可以设置画布的布局，进行对齐操作：左对齐、右对齐、顶部对齐、底部对齐、垂直居中、水平居中、等距分布左右对齐、等距分布上下对齐、相同大小、格式刷。格式刷的详细用法参见 [5.4.5 格式刷](./04-toolbar.md#545-格式刷)。

## 5.3.3 查看图元列表

图元列表列出了画布上的所有图元，按层级分组并在行尾标注所属层级：DOM 图元、模版层图元、底层图元、中层图元、顶层图元。点击其中一个图元，该图元即被选中，并在画布上居中显示。

每个图元行提供两个开关：

- **可见性**：点击眼睛图标，隐藏或显示该图元。
- **锁定状态**：点击锁定图标，在以下四种状态间循环切换：
  1. **可编辑**：默认状态，可自由编辑图元的属性与事件。
  2. **只读**：不可编辑，交互与事件仍可执行。
  3. **禁用移动**：图元位置固定，不可拖动。
  4. **禁用所有事件**：不可选中、不触发任何事件，可当作背景底图。
