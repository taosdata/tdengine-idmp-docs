# 5.5 图元

图元是构成监控画面的基本元素，就像乐高积木一样，每个设备图标、封闭图形都是一个图元。通过组合不同的图元，可以构建出完整的工业监控系统。

对图元的配置，在右侧属性面板中按外观、事件、动画、图元属性四个页签展开，下面分别介绍；更详细的配置方法参见 [5.8 功能点](./08-function-points/index.md)。

## 5.5.1 外观

在右侧属性面板的**外观**页签中配置图元的视觉属性，主要折叠组如下：

### 5.5.1.1 位置与大小

X、Y、宽度、高度、旋转角度、圆角、内边距、进度值等。

### 5.5.1.2 样式

描边与填充：颜色、线型、线宽、线条渐变、背景（纯色/线性/径向渐变）、透明度、阴影、悬停色/选中色等。

### 5.5.1.3 状态

通过「条件 + 外观」为图元定义状态，命中条件后普通图元改变颜色、播放动画，组合图元切换显示对应子图元，详见 [5.8.2 设置图元状态](./08-function-points/02-states.md)。

### 5.5.1.4 端点

连线类图元可配置起点/终点坐标与线帽，参见 [5.7 连线](./07-lines.md)。

### 5.5.1.5 文字

可设置图元上显示文字的字体、大小、颜色、样式、粗细、行高、对齐、所在位置等。

### 5.5.1.6 图片

可以上传图片作为图元的外观或者背景图片。

### 5.5.1.7 字体图标

设置图元的字体图标（iconfont），可调整图标、大小、旋转、颜色与对齐方式。

### 5.5.1.8 禁用

设置图元禁用态下的颜色，并可关闭图元的输入、旋转、缩放、锚点等交互。

## 5.5.2 事件

事件是数据驱动组态画面的核心机制：通过定义事件类型、事件动作与触发条件，图元可以在数据变化或鼠标操作时自动改变展现形式。事件类型包括鼠标移入、移出、单击、双击以及「图元属性值变化」；事件动作包括打开链接、设置图元属性、执行动画、执行 JavaScript 等。详细说明参见 [5.8.6 设置图元事件](./08-function-points/06-events.md)。

## 5.5.3 动画

图元支持内置动画与逐帧自定义动画，让监控画面生动直观。除自动播放外，动画还可由事件触发，例如在「图元属性值变化」事件中配置执行动画。详细说明参见 [5.8.5 设置图元动画](./08-function-points/05-animation.md)。

「动画」页签还提供**鼠标提示**：鼠标悬浮在图元上时显示提示信息，支持参考 Markdown 语法编写提示，或编写 Mark 函数显示返回值。

## 5.5.4 图元属性

除外观样式外，图元还拥有值、状态、进度、文本等数据属性。这些属性既可以在编辑时手动设置静态效果，也可以绑定 IDMP 的元素属性或表达式，由采集到的实时数据自动驱动展示。

- 属性绑定与表达式绑定，参见 [5.8.3 设置图元属性值](./08-function-points/03-property-values.md)
- 进度值设置，参见 [5.8.4 设置进度](./08-function-points/04-progress.md)
- 状态切换，参见 [5.8.2 设置图元状态](./08-function-points/02-states.md)
