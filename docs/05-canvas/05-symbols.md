# 5.5 图元

图元是构成监控画面的基本元素，就像乐高积木一样，每个设备图标、封闭图形都是一个图元。通过组合不同的图元，可以构建出完整的工业监控系统。

图元有各种属性，比如颜色、背景颜色、大小、显示的文本、进度、值、状态等。本章介绍图元的外观设置与鼠标提示；事件以及将多个图元组合为组合图元、设置图元状态、属性值、进度与动画效果等数据驱动的配置方法，参见 [5.8 功能点](./08-function-points/index.md)。

## 5.5.1 外观设置

选中图元后，在右侧属性面板的**外观**页签中配置图元的视觉属性，主要折叠组如下：

### 5.5.1.1 样式

描边与填充：颜色、线型、线宽、线条渐变、背景（纯色/线性/径向渐变）、透明度、阴影、悬停色/选中色等。

### 5.5.1.2 位置与大小

X、Y、宽度、高度、旋转角度、圆角等。

### 5.5.1.3 文字

可设置图元上显示文字的字体、大小、颜色、样式、粗细、行高、对齐、所在位置等。

### 5.5.1.4 图片

可以上传图片作为图元的外观或者背景图片。

连线类图元还提供**端点**（起点/终点坐标与线帽）配置，参见 [5.7 连线](./07-lines.md)。

## 5.5.2 鼠标提示

鼠标悬浮在图元上时，显示鼠标提示信息。支持两种方式：

1. 参考 Markdown 语法编写鼠标提示
2. 编写 Mark 函数，显示函数的返回值
