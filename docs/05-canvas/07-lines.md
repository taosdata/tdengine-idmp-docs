# 5.7 连线

连线用于表示设备之间的物料流动、信号传递或逻辑关系。例如：

1. 管道连接表示物料输送
2. 虚线连接表示信号传输
3. 不同颜色的连线表示不同介质

通过连线动画，可以直观展示物料的实时流动状态。

## 5.7.1 连线的绘制

### 5.7.1.1 钢笔绘制连线

选择线型，再点击钢笔，可激活使用某一个线型的绘制。

开始：单击左键；

暂停：单击右键 或 enter；

结束：esc。

#### 曲线、线段、直线、脑图曲线

可以使用钢笔绘制曲线、线段、直线与脑图曲线；选中一条已绘制的连线后，也可以在右侧属性面板中将线型改为曲线、线段或直线。

#### 横线

按下快捷键 Shift，点击鼠标左键绘制，右键结束绘制（连线类型选择直线）。

#### 竖线

按下快捷键 Ctrl，点击鼠标左键绘制，右键结束绘制（连线类型选择直线）。

#### 斜线

连线类型选择直线，选择钢笔，鼠标左键点击绘制起点，按住快捷键 Ctrl+Shift，鼠标移动角度（以 15° 为递增角度），左键单击绘制第二个点，右键结束绘制。

### 5.7.1.2 铅笔绘制连线

使用铅笔可以绘制任意线型。点击"铅笔"激活铅笔工具，在画布上按下左键开启绘制，将会按照鼠标移动轨迹绘制连线，松开鼠标结束绘制。

### 5.7.1.3 连接图元

鼠标悬浮在某一个图元上，激活锚点，在某一个锚点上按下鼠标拖拽到另一个图元的锚点上，松开鼠标，即可在两个图元的锚点间绘制一条曲线。

### 5.7.1.4 连线变图元

在连线上点击鼠标右键，选择"转换为节点"。

## 5.7.2 切割/合并连线

切割连线：选中线，鼠标移入要断开的线锚点，点击，按下 S 键。

合并连线：线连接线时，拖动当前选中连线连接端，对齐另一条连线连接端，按下 Alt 键，鼠标抬起，结束 Alt 键。

## 5.7.3 连线样式

选中连线后，在右侧属性配置区域可设置连线的外观样式，各配置项如下：

| 配置 | 说明 |
| --- | --- |
| 线条样式 | 线条采用实线或虚线 |
| 连线类型 | 连线形态：曲线、线段或直线 |
| 连接样式 | 折线拐角处的连接方式：斜角、圆角或默认 |
| 末端样式 | 线条末端的形状：默认、圆角或方形 |
| 线条渐变 | 线条颜色是否使用线性渐变 |
| 线条颜色 | 线条的主颜色，并可设置悬停颜色与选中颜色 |
| 线条宽度 | 线条的粗细 |
| 背景 | 背景填充类型：纯色、线性渐变或径向渐变 |
| 背景颜色 | 背景颜色，并可设置悬停背景颜色与选中背景颜色 |
| 透明度 | 线条透明度，取值范围 0-1 |
| 锚点 | 锚点颜色与锚点半径（≥0） |
| 阴影 | 阴影颜色、阴影模糊与阴影 X/Y 偏移 |
| 边框 | 边框颜色与边框宽度（≥0） |

## 5.7.4 连线动画

IDMP 为连线内置了多种动画效果，让画面更有动效。选中连线后，在「动画」页签中可配置以下动画参数：

| 配置 | 说明 |
| --- | --- |
| 动画效果 | 连线动画的类型：水流、水珠流动、圆点；直线与线段还支持箭头、水滴 |
| 动画线宽 | 动画线条的宽度（≥0） |
| 动画颜色 | 动画的颜色 |
| 动画阴影 | 开关，开启后动画带阴影，可设置阴影颜色与阴影模糊 |
| 动画速度 | 动画播放速度，1-5 档可调 |
| 反向流动 | 开关，开启后动画沿连线反向流动 |
| 循环次数 | 动画循环次数，默认无限循环 |
| 下个动画 | 通过 tag 指定当前动画结束后播放下一个动画 |
| 自动播放 | 开关，是否自动播放动画 |
| 保持动画状态 | 开关，动画结束后是否保持最终状态 |
| 线性播放 | 是/否，动画是否以线性速度播放 |

选择不同动画效果时，还会出现对应的子选项：水珠流动可设置动画虚线，圆点可设置圆点大小，箭头可设置动画间隔。
