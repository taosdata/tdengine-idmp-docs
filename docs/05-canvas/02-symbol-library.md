# 5.2 图元库

图元库位于组态编辑器左侧，是搭建监控画面的图元素材库，划分为系统图元、私有图元、面板图元三类。从图元库中选中素材拖拽到画布，即可开始编辑。

## 5.2.1 系统图元

系统图元由 IDMP 内置，能满足大部分行业的基本需求。图元库左侧按用途将系统图元划分为常用、图标、部件、场景、行业、电气六个页签，便于快速定位所需素材。图元格式有三种：原生代码（JS）、字体图标（iconfont）、图片（svg、gif）；video 图元支持 MP4、WebM、Ogg 三种视频格式。

「常用」页签除最近使用与基本形状外，还提供一组交互控件，可拖入画面搭建表格、按钮、开关、进度条、量尺等交互展示。基本形状分组中还提供视频、网页（iframe）等嵌入类图元，其配置详见 [5.8.7 嵌入组件](./08-function-points/07-embed-components.md)。

### 5.2.1.1 常用控件

「控件」分组提供以下交互控件，拖入画面后即可在右侧配置面板中调整外观、选项与取值范围：

| 控件 | 说明 |
| --- | --- |
| 表格 | 以表格形式展示多个属性的实时数据，常用于告警清单与设备状态一览 |
| 按钮 | 可配置鼠标事件的按钮，用于触发交互行为 |
| 开关 | 二态开关，可绑定图元属性随数据切换开/关 |
| 复选框 | 多选选项，可配置选中态与禁用态 |
| 单选框 | 单选选项，支持横向或纵向排列 |
| 进度条 | 展示数值进度的滑杆，可设置取值范围与单位 |
| 量尺 | 刻度标尺，用于直观呈现数值的刻度指示 |
| 输入框 | 可输入文本的输入框 |
| 选择器 | 带下拉选项的选择框 |
| 时间 | 实时显示当前时间，支持自定义时间格式 |

### 5.2.1.2 使用控件

控件与普通图元的使用方式一致，步骤如下：

1. 打开图元库，切换到「常用」页签，在「控件」分组中选中所需控件。
2. 将控件拖拽到画布，并调整其位置与大小。
3. 选中控件，在右侧配置面板中设置外观、选项、取值范围等属性。
4. 需要控件随实时数据变化时，可为其绑定元素属性或配置事件，方法参见 [5.8.3 设置图元属性值](./08-function-points/03-property-values.md) 与 [5.8.6 设置图元事件](./08-function-points/06-events.md)。

## 5.2.2 私有图元

IDMP 的图元库是可扩展、开放性的图形库，可根据不同的需求定制各种组件效果和场景。支持新建私有图元库、上传自行制作的图元（JS、SVG、图片等）；使用过程中如有更多需求，也可联系 IDMP 团队获取相应的设计支持。

## 5.2.3 面板图元

面板图元用于将已有的仪表板面板直接嵌入组态画面：在面板图元列表中选中一张面板拖入画布，即以图元的形式实时展示该面板的数据，鼠标悬浮时可查看数值提示。适合在工艺画面中直接复用趋势图、仪表等既有面板，无需重复配置。

预览态下右键面板图元并选择**查看详情**，可在新标签页中打开该面板的预览页，查看面板的完整内容。
