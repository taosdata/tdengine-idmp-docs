# 7.4 计算

计算区段（分析表单第 4 段）定义实时分析计算什么以及结果存储在哪里。它包含四个部分：**计算对象**、**窗口聚合**、**输出时间戳**和**输出属性**。

## 7.4.1 计算对象

**计算对象**决定实时分析的数据范围——即计算针对当前元素自身的属性执行，还是对其下属子元素的数据进行跨元素聚合。

| 选项 | 说明 |
|---|---|
| **元素本身** | 计算针对元素自身的属性执行。适用于针对单台设备或单个测点进行计算的场景。 |
| **子元素聚合** | 对元素下共享相同模板的子元素数据进行聚合计算。适用于"计算该风电场下所有风机的平均发电功率"等跨子元素的汇总指标。 |

选择**子元素聚合**后，会显示两个附加字段：

| 字段 | 说明 |
|---|---|
| **子元素模板** | 子元素必须匹配的模板。仅具有该模板的子元素参与聚合。若所有子元素共享相同模板，系统将自动预填。 |
| **子表过滤** | 可选的过滤表达式，用于缩小参与聚合的子元素范围。例如，仅筛选处于特定运行状态的子元素。 |

:::note
**子元素聚合**仅在元素包含子元素时可用。对于叶节点元素，此选项处于禁用状态，仅可选择**元素本身**。
:::

## 7.4.2 窗口聚合

**窗口聚合**复选框（默认启用）控制计算是否在时间窗口上进行聚合。

启用时，**间隔**字段指定聚合窗口的长度（数字 + 时间单位）。例如，间隔为 1 小时表示每次触发计算过去 1 小时数据的聚合值。

禁用时，计算在单个数据点上运行，不进行窗口聚合——适用于行级计算或转换。

## 7.4.3 输出时间戳

**输出时间戳**下拉菜单指定每个结果行写入输出属性时使用哪个时间戳：

| 选项 | 说明 |
|---|---|
| **窗口开始** | 窗口开始时间 |
| **窗口结束** | 窗口结束时间（默认） |
| **时间戳** | 原始时间戳（`_c0`），即数据写入时刻。适用于定时触发、异常检测等逐行流式输出场景，保留每条结果的真实采集时间 |
| **表达式** | 由表达式计算输出时间戳。选中后右侧出现表达式输入框，点击打开公式编辑器；表达式可引用源属性、`${attributes[...]}` 占位符与[流计算伪列](#745-流计算伪列)，结果需为 TIMESTAMP。例如 `_twstart`、`_c0 + 1s` 或 `cast(_tlocaltime / 1000000 timestamp)`。表达式模式下偏移量不适用。异常检测与预测不提供时间戳配置 |

选择**时间戳**（`_c0`）时，系统会根据触发类型自动决定输出形式：数据窗口聚合类计算（滑动窗口聚合、计数窗口、会话窗口等）输出聚合时刻 `last(_c0)`；逐行流式计算（定时触发、异常检测、未配置间隔的滑动触发等）直接输出原始 `_c0`。

**偏移量**字段为所选窗口边界添加时间偏移量（数字 + 单位，默认 0 秒），不适用于表达式模式。可用于调整输出时间戳以对齐显示。

## 7.4.4 输出属性

**输出属性**表格定义计算表达式与元素属性（以及在启用事件生成时与事件属性）之间的映射关系。

表格中每行包含以下列：

| 列 | 说明 |
|---|---|
| **表达式** | 计算表达式。点击单元格打开表达式编辑器（参见[第 3.2.10 节](../03-data-modeling/02-attributes.md#3210-表达式编辑器)）。 |
| **目标元素** | 该行计算结果的保存目标元素，默认为当前元素，可切换到其他元素——结果将写入目标元素的属性，便于把聚合/统计结果沉淀到汇总类元素上。分析模板不支持跨元素保存（不显示该列）。 |
| **元素属性** | 计算结果作为新时序值存储的元素属性（跟随该行所选的目标元素） |
| **事件属性** | *（仅在第 3 段启用事件生成时可见）* 在事件触发时刻捕获计算值的事件属性 |

通过表格底部的 **+** 按钮可添加更多输出行。每行对应一个独立的表达式，支持在单个实时分析中计算多个指标并将结果写入不同属性（各行可指定不同的目标元素）。

:::note 表达式中可引用子属性与 KPI 子属性
分析中的表达式（输出属性表达式、触发预过滤、事件窗口条件等）均可引用属性的**子属性**和 **KPI 属性的子属性**。在表达式编辑器的属性树中展开父属性（或 KPI 属性），点击子属性节点即可插入形如 `${attributes['父属性名']|childAttributes['子属性名']}` 的引用；KPI 属性自身无取值，不能被直接引用，必须选择其子属性。

引用已构建完成的 KPI 子属性时，计算实时跟随 KPI 数据；引用构建期或月/季派生的 KPI 子属性时，流中读取的是标签快照值（非精确派生值），如需精确的派生聚合值请使用 KPI 面板或子属性直查。当表达式引用了 KPI 子属性时，界面会在表达式旁显示取数语义提示。引用**公式型子属性**时，公式会被内联展开为对应的 SQL（与面板口径一致），无需物化列。
:::

## 7.4.5 流计算伪列

流计算伪列仅在流计算运行时有效，表达式评估时不予求值，返回空值。输出属性表达式与输出时间戳表达式均可引用；保存时按触发类型与触发时机校验，引用不可用的伪列将返回 400 错误：

| 伪列 | 类型 | 适用触发 | 关窗限制 | 含义 |
|---|---|---|---|---|
| `_twstart` | TIMESTAMP | 窗口聚合类 | 否 | 触发窗口的开始时间 |
| `_twend` | TIMESTAMP | 窗口聚合类 | 是 | 触发窗口的结束时间 |
| `_twduration` | BIGINT | 窗口聚合类 | 是 | 触发窗口的时长（毫秒） |
| `_twrownum` | BIGINT | 窗口聚合类 | 是 | 触发窗口内的数据行数 |
| `_tprev_ts` | TIMESTAMP | 逐行滑动 | 否 | 上一行时间戳 |
| `_tcurrent_ts` | TIMESTAMP | 逐行滑动 | 否 | 当前行时间戳 |
| `_tnext_ts` | TIMESTAMP | 逐行滑动 | 否 | 下一行时间戳 |
| `_tprev_localtime` | BIGINT | 定时、预测 | 否 | 上一周期本地时间（纳秒） |
| `_tnext_localtime` | BIGINT | 定时、预测 | 否 | 下一周期本地时间（纳秒） |
| `_tgrpid` | BIGINT | 全部 | 否 | 分组 ID；无分区时为 0 |
| `_tlocaltime` | BIGINT | 全部 | 否 | 当前本地时间（纳秒，建议 cast） |
| `tbname` | VARCHAR | 全部 | 否 | 源子表名 |

其中「窗口聚合类」指计数、状态、事件、会话、数据输入、SPC 以及配置了窗口间隔的滑动窗口触发；「逐行滑动」指未配置窗口间隔的滑动窗口触发与异常检测。

**关窗限制**：标记为「是」的伪列仅在窗口关闭时输出最终值，仅选择「开窗时」触发时机的分析将在保存阶段被拒绝。此外，`_tlocaltime` 与 `_tprev_localtime`/`_tnext_localtime` 为纳秒值，输出时间戳场景建议用 `cast(_tlocaltime / 1000000 timestamp)` 转换。

在**输出属性**的表达式编辑器中，左树提供**流计算伪列**分类（位于**替换参数**之上），列表随触发类型与触发时机自动过滤——仅展示当前触发可用的伪列；在表达式输入框中键入时，提示列表也会给出对应的快捷补全。系统保留伪列（如 `_event_condition_path`）与查询期伪列（`_qstart`/`_qend`/`_qduration`）不出现在编辑器列表中，手写引用在保存时被拒绝。

## 7.4.6 输出过滤

**输出过滤**是一个可选条件表达式，在实时分析完成计算后、将结果写入输出属性前进行评估。只有当过滤条件为真时，本次计算结果才会写入已配置的元素属性。

该功能适用于只保留满足业务条件的结果，例如仅在窗口内存在有效样本、结果超出允许范围，或某个状态条件成立时才输出。若过滤条件不满足，本次触发仍视为已执行，但不会向输出属性写入结果。
